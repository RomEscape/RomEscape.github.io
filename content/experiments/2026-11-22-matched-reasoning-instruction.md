**A2에서 단계별 풀이를 지시해 더 길어진 문제가, 별도로 다시 풀었을 때 더 많이 맞히는 문제라는 증거는 발견되지 않았다.** GSM8K 1,319문항과 MATH500 500문항에서 처음 두 생성의 추가 토큰으로 문항을 정렬했다. 다음 두 생성에서 상위와 하위 사분위의 정답 이득 차이는 GSM8K +1.37%p(95% 구간 −2.13~+5.03), MATH500 −2.53%p(−9.85~+4.86)였다. 이는 표준 지시와 시스템 지시 전체 제거를 비교한 과거 기록이다.

| 같은 문항에 4회씩 생성한 기존 A2 | 표준 → 시스템 전체 제거 정답률 차이 | 평균 출력 토큰 |
|---|---:|---:|
| GSM8K, 공식 형식 판독 | −7.87%p | 907 → 514 |
| GSM8K, 박스 밖 답과 기존 사람 판독 반영 | +0.30%p | 907 → 514 |
| MATH500, 기존 사람 판독 반영 | +0.80%p | 4,678 → 3,948 |

**현재 시험**은 Qwen2.5-7B-Instruct 기반 LIMO A2와 저자 공개 QFFT에서 답을 박스 안에 쓰라는 문장을 양쪽에 남긴다. 한쪽에만 단계별 풀이 지시를 둔다. 예를 들어 정답이 49인 문제에서 `49`와 박스 안의 `49`를 서로 다르게 판정한 경우를 따로 집계한다. 두 짧은 지시 답이 불일치할 때에만 표준 지시를 쓰는 정책은 같은 생성 기록으로 재생한다. 두 모델 모두에서 정확도 유지와 비용 절감 기준을 넘은 방법만 독립 문항에서 확인한다.

| 패널 | GSM8K / MATH500 / AIME25 / AIME24 / AMC / Minerva | 문항·모델·조건당 반복 |
|---|---|---:|
| 스모크 | 1 / 1 / 1 / 1 / 1 / 1 | 1 |
| 파일럿과 독립 확인 각 패널 | 4 / 5 / 4 / 4 / 2 / 2 | 3 |
| 동일한 방식이 두 패널을 통과했을 때의 확대 | 12 / 15 / 6 / 6 / 4 / 5 | 3 |

출력 예산은 최대 32,000토큰이며 모델의 입력 포함 전체 문맥은 32,768토큰이다. 세 핵심 벤치마크의 변화량을 균등 평균하고 세 보조 벤치마크를 따로 본다. 보존된 16회 표준 기록은 저자 QFFT 6종, A2 3종이다. 과거 16회 기준과 새 패널의 난수 및 실행 방식은 다르며, 직접 개입 비교는 이번 실행의 같은 문항과 시드로 한다.

[캐스케이드](https://arxiv.org/abs/2310.03094) [CAPS](https://arxiv.org/abs/2605.15513) [11월의 자기일관성 연구](https://arxiv.org/abs/2611.11201) | 내부 11/12 cascade 및 11/20 L·R·S, first-two-finished와 겹친다. 이미 생성한 3회에서 분기와 단순 추가 표를 비교하고, 동률·오답 합의와 모든 입력 토큰을 집계한다. 강한 제어군을 이기더라도 그 자체로 신규성 근거가 되지 않는다. |
| 빠뜨린 경우를 찾아 검산 | 11월 14일 Agent-Guided Process Verification은 후보 대입만으로 놓치는 필수 분기를 직접 지적한다. ProcessBench는 중간 오류 위치를 평가한다. MATH-Perturb는 풀이법이 보존되거나 깨지는 변형을 구분한다. [분기 누락과 검산](https://arxiv.org/abs/2611.19122) [ProcessBench](https://arxiv.org/abs/2412.06559) [MATH-Perturb](https://proceedings.mlr.press/v267/huang25k.html) | 내부 11/20 J는 부분해의 합집합, M은 예제 풀이의 적용 조건, shared-premise는 두 풀이의 공통 줄을 검산했다. 단순히 누락된 분기를 찾아 더 푸는 아이디어는 보류한다. |
| 추가 계산이 실제 이득을 주는 문제에 쓰이는가 | Beyond Answers, Traces, and Efficiency는 정확도·흔적·비용만으로 적응성을 단정하기 어렵다고 지적한다. Effort Economics는 추가 계산의 한계가치를 관측하기 어려운 점을 다룬다. [적응성의 행동 증거](https://arxiv.org/abs/2611.02704) [추가 계산의 가치](https://arxiv.org/abs/2610.34491) | 내부 U·V·X는 추론 강도·투표·다른 데이터로의 전이를, L은 같은 문제에서 추가 표의 가치를 다뤘다. 이번에는 같은 체크포인트의 문항별 지시 효과에서, 독립 생성으로 추가 길이가 큰 문항의 정답 이득을 검산한다. 목적은 평균 단축과 계산 배분 효과를 분리하는 것이다. 현상이나 방법의 최초성은 미확정이다. |

예를 들어 긴 지시가 300토큰을 더 쓴 문제와 3,000토큰을 더 쓴 문제가 있을 때, 별도 생성에서 후자에 정답 이득이 더 큰지를 본다. 같은 출력에서 길이와 성공을 함께 골라 결론 내리지 않는다. 쉬운 계산과 어려운 계산에서 같은 방향인지, 표기 복원으로 결론이 바뀌는지, 다른 모델로 전이되는지가 중요하다. 반복해서 성립하는 차이가 없으면 이를 학습 표적이나 정책으로 넘기지 않는다.

검토 범위는 arXiv, ACL Anthology, PMLR의 가장 가까운 원문과 프로젝트 홈페이지, 두 일지, 실제 평가 아카이브다. 검색어는 reasoning interfaces / prompt brevity, adaptive cascades / disagreement / self-consistency, proof completeness / missing branches, adaptive effort / marginal value of compute였다. 새로운 기전 등록 전에는 원문 방법·데이터·대조군을 다시 대조한다. 자동 메타데이터 검색은 읽을 논문을 찾는 보조 도구이며 그 결과만으로 신규 기전을 승인할 수 없다.
