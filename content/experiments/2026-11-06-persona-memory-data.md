## 한 줄 요약

사용자가 대화 앞부분에서 밝힌 자기 사정을 모델이 기억하는지 묻는 질문에 약했습니다. 원인은 학습 자료에 그런 대화가 거의 없고(인물마다 0~5개), 실행 코드가 기억 질문에도 인물 프로필 문단을 붙여 모델이 **사용자의 이야기와 자기 이야기를 헷갈린 것**이었습니다. 기억 질문이 들어온 차례에만 프로필 검색을 끄고 사용자가 밝힌 문장을 그대로 붙이는 규칙을 만들었고, 기억 대화 자료도 새로 만들었습니다. 그 자료를 LLM 자동 평가로 두 번 검토했더니 세 인물 모두 기준(20개 중 큰 문제 2개 이하)에 못 미쳤습니다. 큰 문제의 뿌리는 **프로필에 적어 둔 모델용 메모("단정하지 않는다", "지어내지 않는다")가 인물의 말투로 옮겨진 것**이었습니다.

## 왜 필요했나

대화 품질 시험(T-002)은 인물마다 10차례짜리 대화 10건을 사람이 채점합니다. 30건 모두 마지막 10번째 차례가 "제가 처음에 말씀드린 사정을 기억하시나요?" 같은 질문이고, 30건 중 13건은 앞 차례에 사용자가 자기 정보를 밝히고 뒤에서 그것을 물어봅니다. 그런데 학습 자료를 규칙으로 세어 보니 이런 대화가 거의 없었습니다.

표 읽는 법: 학습 자료 판마다 "앞에서 밝히고 뒤에서 기억해 달라는" 대화가 몇 개인지 셌습니다.

| 학습 자료 | 기억을 요구하는 대화 수 |
|---|---|
| 조수미(시험용 2.4B의 자료, 개선 시도 자료) | 1, 1 |
| 김홍도(시험용 2.4B의 자료, 11월 개선 자료) | 0, 0 |
| 정선(시험용 2.4B의 자료, 11월 개선 자료) | 0, 5 |
| 대화 품질 시험 30건 | 13 |

시험 대화를 LLM 자동 평가로 읽은 메모에서도 약점이 같았습니다. 조수미 모델은 10건 중 9건에서 기억에 실패하거나 관점이 뒤바뀌었습니다(사용자가 한 이야기를 자기 이야기처럼 말함).

## 용어 풀이

| 용어 | 뜻 | 이 글에서의 실제 값 |
|---|---|---|
| 기억 질문 | 사용자가 앞에서 밝힌 자기 사정을 모델이 기억하는지 묻는 말 | "제가 앞서 말씀드린 사정을 기억하시나요?" |
| 프로필 검색(RAG) | 질문과 관련된 인물 프로필 문단을 찾아 모델 입력에 붙이는 것 | 기억 질문에도 프로필 문단이 붙었음 |
| 대화 기억 메모 | 기억 질문이 들어온 차례에 사용자가 밝힌 문장을 원문 그대로 모아 붙이는 규칙 | 앞 3줄 + 뒤 5줄까지, 모델 호출 없음 |
| 관점 뒤바뀜 | 사용자의 이야기를 인물이 자기 경험처럼 말하는 것 | 조수미 모델 10건 중 9건(기억 실패와 합한 수) |
| 얼버무림 말투 | 인물이 자기 일을 남의 기록처럼 흐리게 말하는 것 | "분명히 말하기 어렵네", "기록이 엇갈리오" |
| 모델용 메모 | 프로필 안에 모델에게 주는 지시로 적어 둔 문장 | "단정하지 않는다" 44곳, "지어내지 않는다" 21곳 |
| 큰 문제 | 검토 기준에서 그 대화를 학습에 쓰면 안 될 정도의 문제 | 기준: 인물마다 20대화 중 2개 이하 |

## 무엇을 했나

1. **원인 찾기(재현).** 시험 대화 300차례에 시험판과 같은 검색을 다시 돌려, 어떤 프로필 문단이 붙었는지 셌습니다. 10번째 차례(기억 질문)에는 세 인물 모두 10건 중 10건에서 인물 프로필 문단이 붙었습니다. 또 시험판은 최근 8차례만 원문으로 넣고 그보다 앞은 짧은 메모로 줄여서, 10번째 차례에는 사용자가 이름을 밝힌 1번째 차례가 메모로 밀려났습니다.
2. **대화 기억 메모 규칙.** 기억 질문을 감지하면 그 차례에는 인물 프로필 검색을 끄고, 앞선 대화에서 사용자가 자기에 대해 밝힌 문장을 원문 그대로 붙입니다. 밝힌 말이 없으면 "아직 듣지 못했다고 하라"는 메모를 붙입니다. 시험판과 공식 고정본에는 넣지 않고 새 판 사본에만 넣었습니다.
3. **기억 대화 자료 만들기.** 인물마다 기억 대화 600개, 꼬리 묻기 150개, 사실 문답(조수미) 200개 또는 자기 작품 이야기(화가) 150개를 LLM으로 만들고, 말씨, 목록 꾸밈, 3인칭, 같은 문장 반복 같은 규칙으로 걸렀습니다. 대화 길이는 6~10차례, 사용자 이름과 밝힐 정보 2~3개를 미리 정했습니다. 시험 질문과 겹치는 대화는 버렸습니다.
4. **검토(미리 정한 규칙).** 결과를 보기 전에 기준을 적었습니다: 인물마다 통과 대화에서 20개를 뽑아, LLM 자동 평가로 기억, 관점, 사실, 말씨, 형식을 보고, 큰 문제가 2개 이하이면 받아들입니다. 1회차 불합격 뒤 규칙 8가지로 거르고, 겹치지 않는 새 표본으로 2회차를 했습니다.
5. **원인 정리와 프로필 고침.** 화가 프로필의 모델용 메모를 사실과 나눈 새 판을 만들고, 문제 문장이 든 답만 골라 1인칭 기억 말투로 고쳐 쓰기 시작했습니다.

## 실제 예시

설명용 예시입니다(시험 대화 원문이 아니라 같은 꼴로 만든 예).

```
1번째 차례  사용자: 저는 민지예요. 평일엔 저녁에 20분 정도만 연습할 수 있어요.
   …
10번째 차례 사용자: 제가 처음에 말씀드린 사정을 기억하시나요?
```

- **규칙 적용 전:** 10번째 차례 입력에 "바쁜 일정 속에서도 짧게 연습한다" 같은 **인물 프로필 문단**이 붙고, 1번째 차례는 짧은 메모로 줄어 있습니다. 모델은 붙은 문단을 자기 이야기로 받아 "저도 하루에 짧게 연습하던 시절이…"처럼 답하기 쉽습니다.
- **규칙 적용 뒤:** 프로필 문단은 붙지 않고, 사용자가 밝힌 "저는 민지예요.", "평일엔 저녁에 20분 정도만 연습할 수 있어요." 같은 문장이 메모로 붙습니다.

검토에서 걸린 얼버무림 말투는 생성 자료에서 실제로 나온 표현입니다: "분명히 말하기 어렵네", "내 그림으로 알려져 있네", "기록이 엇갈리오", "보태지 않겠소". 화가가 **자기 그림, 자기 집 이야기를** 남의 기록처럼 말한 것입니다.

## 결과

### 대화 기억 메모 규칙

표 읽는 법: 언어 모델 대신 가짜 엔진을 붙이고 실제 시험판 코드와 검색으로 마지막 차례 입력이 어떻게 바뀌는지 셌습니다(규칙 측정).

| 항목 | 조수미 시험판 코드, 전 → 뒤 | 김홍도 시험판 코드, 전 → 뒤 |
|---|---|---|
| 기억 질문 차례에 인물 프로필 문단이 붙은 대화 | 9/10 → 0/10 | 10/10 → 0/10 |
| 사용자 메모가 붙은 대화 | 0/10 → 10/10 | 0/10 → 10/10 |

- 감지 규칙은 새로 만든 대화의 마지막 기억 질문 1,158개를 모두 잡았고, 다른 차례에서 잘못 잡은 것은 13,110개 중 27개였습니다(모두 사용자 사정을 가리키는 요청).
- 시험 대화에서는 처음 규칙이 10번째 차례 30개 중 22개를 잡았습니다. 놓친 꼴을 더한 뒤 30개를 모두 잡았지만, **시험 결과를 보고 규칙을 넓혔으므로 30/30은 치우친 값**입니다.

### 기억 대화 자료

표 읽는 법: 만든 대화 가운데 규칙 검사를 통과한 수입니다(분모는 만든 수).

| 인물 | 기억 대화 | 꼬리 묻기 | 사실 문답 또는 자기 작품 |
|---|---|---|---|
| 조수미 | 496/600 | 144/150 | 173/200 |
| 김홍도 | 319/600 | 105/150 | 119/150 |
| 정선 | 343/600 | 123/150 | 123/150 |

화가 기억 대화가 많이 떨어진 가장 큰 까닭은 말씨 이탈이었습니다.

### 검토(LLM 자동 평가, 사람 점수 아님)

표 읽는 법: 인물마다 20대화를 뽑아 큰 문제가 있는 대화 수를 셌습니다. 기준은 2개 이하입니다.

| 인물 | 1회차 큰 문제 | 거른 뒤 2회차 큰 문제 | 판정 |
|---|---|---|---|
| 조수미 | 7/20 | 6/20 | 불합격 |
| 김홍도 | 9/20 | 13/20 | 불합격 |
| 정선 | 12/20 | 13/20 | 불합격 |

- **좋았던 점:** 기억 대화의 마지막 되짚기는 두 회차 표본 모두 정확했고, 관점과 형식도 거의 문제가 없었습니다.
- **큰 문제의 대부분:** 화가가 자기 작품, 집, 인간관계를 얼버무리는 말투. 규칙 거르기로는 말 바꿈이 너무 다양해 정선 표본 20개 중 11개가 넓힌 규칙도 빠져나갔습니다.

### 원인: 프로필의 모델용 메모

| 항목 | 김홍도 | 정선 |
|---|---|---|
| 프로필 문장 가운데 모델용 메모 | 62/390 | 58/392 |
| 생성 자료 답 중 얼버무림 표현 비율 | 19.2% | 20.7% |
| 기존 일반 대화 학습 자료의 같은 비율 | 12.8% | 10.3% |
| 프로필 새 판(사실과 메모 분리) 글자 수 | 17,974 → 14,125 | 16,334 → 12,848 |

조수미는 얼버무림 비율이 생성 자료 2.8%, 기존 자료 2.4%로 낮았습니다.

## 그래서 무슨 뜻인가

- 기억 질문에 약한 까닭은 모델의 능력보다 **자료와 실행 코드**에 있었습니다. 학습 자료에 예가 거의 없었고, 실행 코드가 엉뚱한 문단(인물 프로필)을 붙였습니다.
- 프로필에 "단정하지 말라"고 적어 두면 모델은 그것을 지시로 따르기보다 **인물의 말버릇으로 배웁니다.** 프로필은 검색으로 모델 입력에 그대로 들어가고, 학습 자료를 만드는 LLM에게도 그대로 보이기 때문입니다. 지시는 지시 자리에, 사실은 사실 자리에 두어야 합니다.
- 같은 말투가 이미 쓰고 있는 화가 학습 자료에도 10~13% 들어 있다는 것도 함께 드러났습니다.

## 한계와 남은 일

- 대화 기억 메모 규칙은 가짜 엔진으로만 시험했습니다. 실제 모델 답이 좋아지는지는 아직 재지 않았습니다.
- 고쳐 쓰기는 일부만 끝난 채 멈췄습니다(보강 대화 조수미 374, 김홍도 544, 정선 591개 고침, 기존 화가 자료 김홍도 776개 고침, 정선은 거의 시작 전). 이어 할지, 범위를 줄일지 결정을 기다립니다.
- 프로필 새 판에서 문장이 모두 메모였던 절(예: 출생지)은 통째로 빠져, 그 주제는 검색 근거가 없습니다.
- 고친 자료로 3회차 검토를 하고, 통과하면 새 학습 자료로 묶어 다시 학습할 계획입니다. 학습용 GPU는 아직 정하지 않았습니다.
