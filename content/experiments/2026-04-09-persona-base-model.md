## 한 줄 요약

조수미 대화 자료로 크기와 계열이 다른 기반 모델 7개를 학습해 비교했더니 **EXAONE 3.5(7.8B)가 평균 6.77점으로 가장 높았습니다.** 그래서 이후 세 인물 모두 EXAONE 3.5를 바탕으로 삼았습니다. 다만 이 시기 점수는 거의 모두 6점대 후반에 몰려 있어서, 선호 학습(DPO)이나 문서 검색(RAG)의 효과를 가려내지 못했습니다. 같은 시기에 **모델 크기를 잘못 알고 있던 일**과 **학습 형식과 추론 형식이 어긋나 기능이 통째로 꺼져 있던 일**을 찾아 고쳤습니다.

## 왜 필요했나

- 인물 대화 모델은 한국어 말투가 자연스러워야 하고, 프로필 사실을 잘 기억해야 하며, 실제 서비스에서 빠르게 답해야 합니다.
- 모델이 클수록 품질은 좋아지지만 느려지고 메모리를 많이 씁니다. 어느 기반 모델이 이 일에 맞는지 같은 자료로 비교해야 했습니다.

## 용어 풀이

| 용어 | 뜻 | 이 글에서의 실제 값 |
|---|---|---|
| 기반 모델 | 학습을 시작할 때 쓰는 이미 만들어진 언어 모델 | EXAONE 3.5, gpt-oss-20b, Qwen3 등 7개 |
| 7.8B, 2.4B | 모델의 매개변수(가중치) 수. B는 10억 | EXAONE 3.5는 7.8B와 2.4B 두 크기 |
| 전체 파인튜닝(Full-FT) | 모델의 가중치 전부를 학습하는 방식 | EXAONE 3.5 7.8B |
| QLoRA | 기반 모델을 4비트로 줄여 고정하고 작은 덧붙임 가중치만 학습하는 방식 | gpt-oss-20b(모델이 커서 이 방식으로) |
| 선호 학습(DPO) | 같은 질문의 좋은 답과 나쁜 답을 짝지어, 좋은 쪽을 고르도록 학습하는 방식 | 짝 수: 조수미 500, 김홍도 483, 정선 378 |
| 문서 검색(RAG) | 질문과 관련된 프로필 문단을 찾아 답 앞에 붙이는 방식 | 아래 표의 "RAG O" |
| Neeko 평가 | Neeko(EMNLP 2024) 논문의 7개 항목을 평가 모델이 1~7점으로 매기는 방식 | 평가 모델 gpt-3.5-turbo |
| 천장 효과 | 점수가 최고점 근처에 몰려 모델 사이 차이가 드러나지 않는 것 | 대부분 6.6~6.9점 |
| 에폭 | 학습 자료 전체를 한 번 다 보는 단위 | 10에폭 |
| (thinking), (speaking) | Character-LLM 형식에서 인물의 속생각과 실제 발화를 나누는 표시 | 학습 후 (thinking)이 0번 나옴 |

## 무엇을 했나

1. **같은 자료, 다른 기반 모델.** 조수미 대화 자료로 7개 기반 모델을 학습했습니다. 2.3B~8B는 전체 파인튜닝, gpt-oss-20b는 QLoRA입니다.
2. **인터뷰 평가.** 생애 사건, 주변 인물과의 관계, 취향, 관점과 신념 4가지 주제로 질문을 만들었습니다(질문 생성은 GPT-4.1-mini). 한 번 묻는 질문 100개, 이어서 묻는 대화 50개입니다.
3. **채점.** gpt-3.5-turbo가 Neeko의 7개 항목(행동, 말투, 가상 지식, 실제 지식, 환각, 관련성, 안정성)을 1~7점으로 매겼습니다.
4. **DPO 자료 만들기.** 프로필로 일반 인터뷰 질문을 만들고, 학습한 인물 모델의 답과 큰 범용 LLM의 답을 1~10점으로 채점했습니다. **두 점수 차가 3점 이상인 짝만** 좋은 답(점수 높은 쪽)과 나쁜 답으로 남기고 나머지는 버렸습니다.
5. **DPO와 RAG 유무 비교.** 세 인물 × 두 기반 모델 × (DPO, RAG) 조합을 같은 방식으로 채점했습니다.
6. **크기 확인과 다시 학습.** 2.4B 결과를 정리하다 체크포인트 설정 파일을 열어 보니 층 수 32, 은닉 크기 4096으로 7.8B 구조였습니다. 2.4B 기반 모델로 처음부터 다시 학습했습니다(조수미, 10에폭, 약 1.5시간).
7. **속생각 출력 문제 진단.** 학습한 모델이 (thinking)을 한 번도 내지 않아 학습 자료부터 추론 프롬프트까지 형식을 하나씩 대조했습니다.

## 실제 예시

평가 모델이 차이를 얼마나 못 가렸는지 보여 주는 실제 채점 예입니다. 정선에게 "시, 글씨, 그림을 하나로 아우르는 예술을 어떻게 실천했나"를 물은 두 답입니다.

| 답 | 내용 요약 | 평가 모델 점수(7개 항목 평균) |
|---|---|---|
| A | 세 예술의 개성을 지키며 조화를 이루는 어려움을 설명 | 6.71 |
| B | 정선과 시대가 맞지 않는 인물(명성황후)에게 영감을 받았다고 답함 | 6.71 |

B는 역사적으로 맞지 않는 답인데도 항목별 점수가 A와 하나도 다르지 않았습니다(행동 7, 말투 7, 가상 지식 6, 실제 지식 7, 환각 7, 관련성 7, 안정성 6). 이런 채점으로는 모델 사이의 작은 차이를 믿기 어렵습니다.

### 2. DPO와 RAG를 붙였을 때

표 읽는 법: 인물마다 세 줄씩, 아무것도 안 붙인 모델(DPO X, RAG X), DPO만, DPO와 RAG 모두를 붙인 모델의 Neeko 평균입니다(gpt-3.5-turbo 평가).

| 인물 | 기반 모델 | DPO X, RAG X | DPO O, RAG X | DPO O, RAG O |
|---|---|---|---|---|
| 조수미 | gpt-oss-20b QLoRA | 6.59 | 6.79 | 6.76 |
| 김홍도 | gpt-oss-20b QLoRA | 6.79 | 6.82 | 6.85 |
| 정선 | gpt-oss-20b QLoRA | 6.75 | 6.81 | 6.81 |
| 조수미 | EXAONE 3.5 7.8B 전체 | 6.77 | 6.66 | 6.75 |
| 김홍도 | EXAONE 3.5 7.8B 전체 | 6.70 | 6.60 | 6.70 |
| 정선 | EXAONE 3.5 7.8B 전체 | 6.73 | 6.67 | 6.79 |

gpt-oss-20b에서는 DPO가 조금 올렸고(최대 +0.20), EXAONE에서는 DPO만 붙이면 오히려 조금 내려갔습니다(−0.06 ~ −0.11). 어느 쪽이든 0.2점 이하의 차이라 **이 평가로는 효과가 있다고 말할 수 없습니다.**

### 3. "2.4B"가 사실은 7.8B였다

| 항목 | 값 |
|---|---|
| 학습 명령에 적은 기반 모델 | EXAONE-3.5-2.4B-Instruct |
| 체크포인트 설정 파일 | 층 32개, 은닉 크기 4096(7.8B 구조) |
| 추정 원인 | 이미 있던 7.8B 체크포인트 위에 덮어 학습 |
| 조치 | 이 결과를 "2.4B" 표에서 지우고 2.4B로 처음부터 다시 학습 |

다시 학습한 진짜 2.4B 조수미 모델은 평균 6.78점, 7.8B는 6.81점이었습니다(gpt-3.5-turbo 평가). 이 점수만 보면 크기가 3분의 1인 모델이 거의 같은 품질로 보였지만, 아래 "한계"의 이유로 이 결론은 나중에 다시 검토했습니다([2.4B와 7.8B 비교 기록](2026-10-21-persona-model-size.html)).

### 4. 속생각 출력이 한 번도 나오지 않은 이유

Character-LLM 형식은 인물의 속생각 `(thinking)`과 실제 말 `(speaking)`을 나눠 씁니다. 학습한 모델은 `(speaking)`만 냈습니다. 원인은 네 가지였습니다.

| 번호 | 원인 | 결과 |
|---|---|---|
| 1 | 대화를 읽어 내는 코드가 `(thinking)`의 괄호를 지워 `thinking`으로 저장 | 학습 자료에 괄호 없는 표시가 섞임 |
| 2 | 대화 자료는 괄호 없음, 할루시네이션 대응 자료는 괄호 있음 | 한 학습 자료 안에 두 형식이 섞임 |
| 3 | 추론 프롬프트가 `조수미 (`로 끝남 | 괄호 뒤에 가장 자주 본 `speaking):`만 이어 씀 |
| 4 | 턴 구분이 학습 때는 `<|eot|>`, 추론 때는 빈 줄 | 학습에서 본 구조와 다른 입력 |

괄호를 보존하도록 고치고 학습 자료의 표시 32,263개를 다시 만든 뒤, 추론 프롬프트와 턴 구분을 학습 형식과 똑같이 맞췄습니다. 학습 자료는 조수미 3,068행, 김홍도 2,794행, 정선 3,188행이 되었습니다.

### 5. 이 시기 학습 설정

표 읽는 법: 5~6월 비교 실험에 쓴 값입니다. 이후 10월부터는 학습 방식이 바뀌었습니다(4비트 오차를 미리 익히는 양자화 학습, 최대 길이 8,192).

| 항목 | 전체 파인튜닝 | QLoRA |
|---|---|---|
| 에폭 | 10 | 10 |
| 학습률 | 2e-5 | 2e-4 |
| 학습률 스케줄, 워밍업 | 코사인, 0.04 | 코사인, 0.04 |
| 가중치 감쇠 | 0.1 | 0.1 |
| 전체 배치 | 64(장치당 4 × 누적 16) | 64 |
| 최대 길이 | 2,048 | 2,048 |
| 정밀도 | bf16 | 4비트(NF4) + bf16 |

DPO는 5에폭, 학습률 5e-7, beta 0.1, 전체 배치 32로 학습했습니다.

## 그래서 무슨 뜻인가

- **기반 모델은 EXAONE 3.5로 정했습니다.** 7개 중 평균이 가장 높았고, 특히 인물 고유 지식과 관련성 항목에서 앞섰습니다. 한국어 학습량이 많은 모델이 한국어 인물 대화에 유리했습니다.
- **평가 모델이 점수를 가려내지 못하면 다음 결정도 흔들립니다.** 시대가 틀린 답이 정상 답과 같은 점수를 받는 채점으로는 DPO, RAG, 모델 크기의 효과를 판단할 수 없었습니다. 이 문제는 뒤에 평가 체계를 다시 만드는 일로 이어졌습니다([LLM 자동 평가를 믿을 수 있게](2026-11-02-persona-judge-reliability.html)).
- **학습 형식과 추론 형식은 글자 하나까지 같아야 합니다.** 괄호 하나, 턴 구분 하나가 어긋나자 기능 하나가 통째로 사라졌습니다.
- **결과를 정리할 때 설정 파일을 직접 확인해야 합니다.** 파일 이름만 믿었다면 7.8B 결과를 2.4B 결과로 보고했을 것입니다.

## 한계와 남은 일

- 이 글의 점수는 모두 gpt-3.5-turbo 평가입니다. 이 평가 모델은 2026년 10월에 서비스가 끝났고, 11월에 다시 검증해 고른 평가 모델(gpt-6-luna)은 같은 답에 평균 6.64점 대신 5.21점을 줬습니다. 두 방식 점수의 상관은 0.03이었습니다. **이 글의 6점대 점수는 지금 점수와 비교할 수 없습니다.**
- "2.4B와 7.8B가 거의 같다"는 결론도 점수가 천장에 붙어서 생긴 착시일 수 있습니다. 실제로 10월의 더 엄격한 비교에서는 2.4B가 앞 답의 문장을 그대로 반복하는 문제가 훨씬 많았습니다.
- DPO 짝을 만든 기준(점수 차 3점)은 이 채점 결과에 기대고 있어, 채점이 흔들리면 짝의 품질도 흔들립니다.
