**추가 추론은 두 모델의 정답 수를 늘렸지만, 두 모델 모두 같은 문제에서 옳은 수를 버리고 같은 오답을 선택했습니다.** 모델이 언제 더 풀어야 하는지 찾기 위해 Qwen2.5-7B-Instruct 기반 LIMO A2와 QFFT 논문 저자가 공개한 QFFT-LIMO-7B를 평가했습니다. A2는 LIMO 학습에서 질문을 지우고 첫 응답 토큰의 학습 손실을 제외한 모델입니다. 이번 기록은 두 기존 모델의 추론 실험입니다. [QFFT 원 논문](https://arxiv.org/abs/2506.12860)

## 같은 풀이를 지금 끝낼 때와 더 풀 때

두 모델 모두 과거에 2,048토큰을 넘겨 풀었던 MATH500 정수 정답 문제 16개를 선정했습니다. 각 모델에서 한 문제의 같은 2,048토큰까지를 고정하고 답을 즉시 쓰는 경우와 그 자리에서 새로 한 번 이어 쓰는 경우를 비교했습니다. 장문 생성의 총 풀이 상한은 32,000토큰이고 전체 문맥 한도는 32,768토큰입니다. A2는 보관된 원래 토큰 ID를, 저자 QFFT는 저장된 원문을 무손실로 다시 토큰화한 ID를 사용했습니다.

| 모델 | 지금 답할 때 | 더 풀 때 | 오답을 고침 | 정답을 잃음 |
|---|---:|---:|---:|---:|
| LIMO A2 | 6/16 | 9/16 | 4 | 1 |
| 저자 QFFT | 6/16 | 7/16 | 2 | 1 |

**추가 계산을 네 문제에만 줄 때도 결과를 비교했습니다.** 예를 들어 모델의 잠정 답이 17이라면 일반 재질문은 17을, ‘답에 1을 더해 달라’는 지시는 18을 기대합니다. 두 답을 원래 값으로 환산해 불일치하는 문제에 더 생각할 기회를 먼저 줬습니다. 이 방식과 일반 재질문 방식의 정답 수는 A2에서 8 대 7, 저자 QFFT에서 6 대 6이었습니다. 고정한 순서대로 네 문제를 고른 단순 기준도 각각 8개와 6개였습니다. 이미 풀이가 끝나고 최종 정수가 확정된 경우에도 세 판독이 모두 들어맞지 않은 사례가 A2 10/14, 저자 QFFT 7/12였습니다. 변환 지시 자체가 풀이 상태를 안정적으로 읽어내지 못해 사전에 정한 기준에 따라 독립 확인 단계를 보류했습니다.

## 같은 정답을 같은 오답으로 바꾼 이유

MATH500 332번은 양수 세 개가 `xyz(x+y+z)=1`일 때 `(x+y)(y+z)`의 최솟값을 묻습니다. 목적식은 `xz + y(x+y+z)`이고 두 항의 곱이 1이어서 합은 2 이상입니다. `x=z=1, y=√2−1`을 대입하면 두 항이 모두 1이므로 정답 2를 달성합니다.

두 모델 모두 중간에 답만 쓰도록 하면 2를 냈습니다. 당시 둘 중 어느 풀이도 하한과 달성 조건을 함께 증명하지는 못했습니다. 같은 자리에서 자연스럽게 이어 쓰게 하자 두 모델은 모두 세 변수를 같게 둔 점을 최솟값의 근거로 삼았습니다. 제약식에서 변수의 자리를 바꿀 수 있어도 목적식에서 가운데 변수 `y`의 역할은 다릅니다. 세 변수를 같게 두면 `4/√3`이 나오며 A2가 제출한 `4√3/3`도 이 값과 같습니다.

| 과거 자연 생성에서 확인한 사례 | A2 | 저자 QFFT |
|---|---:|---:|
| 332번에서 세 변수를 같게 두었을 때의 값으로 끝남 | 11/16 | 5/16 |
| 184번에서 틀린 하한 5/2로 끝난 풀이 중, 그전에 옳은 하한 2를 지지했음 | 5/9 | 5/6 |
| 355번에서 틀린 최솟값 120으로 끝난 풀이 중, 그전에 옳은 최솟값 100을 지지했음 | 0/7 | 0/4 |

332번의 중간 답과 장문 답은 같은 토큰에서 분기한 별도 생성입니다. 184번과 355번에서는 해당 오답으로 끝난 자연 풀이 26개를 처음부터 끝까지 읽었습니다. 184번은 모델별 전체 16회 가운데 각각 9회와 6회가 틀린 하한으로 끝났습니다. 이 가운데 두 모델 모두 같은 풀이 안에서 올바른 하한을 받아들였다가 바꾸는 행동을 보였습니다. 355번에서는 100을 계산하고도 120을 답한 경우가 있었지만, 그 전에 100을 전역 최솟값으로 채택했다는 근거는 없었습니다.

MATH500과 추가 다섯 벤치마크 1,691문항을 살폈습니다. 최초 사례 밖에서 옳은 후보를 채택했다가 이 특정 대칭 오답으로 되돌아가는 과정까지 확인한 원문은 184번 하나였습니다. 여러 시드에서 같은 행동이 반복돼도 독립 문항 수는 늘지 않습니다.

## 일곱 실험에서 선별한 결과

각 스모크의 본 비교는 96개로 총 672개입니다. 강제 답 제출, 새 장문 이어쓰기와 종료 후 판독을 포함한 실제 생성은 855회였습니다. 아래의 8회짜리 칸은 서로 다른 원 문제나 자료 4개를 시드 2개로 반복한 값입니다. B1은 서로 다른 8문항, C1은 16문항을 썼습니다. 모든 후보가 사전에 정한 확대 기준에 미달했습니다. [처음 세 후보의 설계와 입력 예시](2026-11-19-c-adaptive-reasoning-candidates.html)

| 실험 | 비교한 조건 | 관찰한 결과 |
|---|---|---|
| W1. 제약 위반 피드백 | 잘못된 배정 초안에 피드백 없음, 위반 알림, 위반 위치 제시 | 정답은 순서대로 A2 6·4·5/8, 저자 QFFT 5·7·4/8이었습니다. |
| R1. 일부 계산만 다시 풀기 | 값을 고친 뒤 영향받는 식만 재계산하거나 전부 재계산 | 이전 잘못된 값이 남은 조건에서 A2는 선택적 재계산 7/8, 전체 재계산 8/8이었습니다. 평균 입력·출력도 1,585 대 1,006토큰이었습니다. |
| G1. 목표에 따라 검산하기 | 질문이 요구한 답이 기호 대응에 민감할 때만 검산하거나 항상 검산 | 대응을 바꿔도 답이 같은 조건에서 두 방식 모두 양 모델 8/8이었습니다. 선택적 검산 쪽이 평균 입력·출력 토큰을 더 썼습니다. |
| N1. 자연 풀이의 산술 오산 | 피드백 없음, 오류 여부 알림, 피연산자 제시 | 오류가 있는 풀이에서 양 모델 모두 각각 3·2·4/8이었습니다. 48개 응답 중 틀린 식을 고친 경우 23개, 고친 값을 쓴 경우 19개, 그중 최종 정답은 14개였습니다. |
| B1. 문제별 추가 예산 | 2,048과 8,192토큰 예산에 같은 최종 답 제출 절차 적용 | 정답은 A2 9→10/16, 저자 QFFT 10→12/16이었습니다. 평소 길게 풀수록 틀렸던 문제가 더 큰 이익을 얻는다는 경향은 두 모델에서 재현되지 않았습니다. |
| X1. 앞 풀이의 메모 재사용 | 결함이 있는 항을 써야 하는 후속 질문에 메모 없음, 오류 메모, 수정 메모 제공 | 메모에서 예측한 특정 오답이 순서대로 A2 2→5→2/8, 저자 QFFT 2→6→1/8이었습니다. 증가분은 원 자료 네 개 중 두 개에 집중됐습니다. |
| C1. 중간 답으로 계산 배정 | 같은 중간 풀이의 직접 답, 일반 재질문, ‘답+1’ 판독을 비교해 네 문제에 추가 계산 배정 | 변환 판독은 고정 순서 배정과 같은 정답 수를 냈습니다. |

**원문 판독이 해석을 바꾼 예도 있습니다.** X1에서 오류 항을 사용하지 않는 후속 질문에 수정 메모를 줬을 때 저자 QFFT의 엄격한 자동 채점은 5/8이었습니다. 나머지 세 답도 마지막 문장에 411, 2, 8을 각각 올바르게 명시했습니다. 이 조건의 수학적 정답은 원문 검산에서 8/8이었습니다. 오류 항을 사용하는 질문에서는 메모 없는 기준 정답이 A2 4/8, 저자 QFFT 3/8이라 사전 하한 5/8에 미달했습니다.

**비용은 앞선 풀이를 다시 읽는 방식에 민감했습니다.** B1의 저자 QFFT는 자연 생성과 8,192토큰 정책에서 모두 12/16을 맞혔습니다. 엔진이 보고한 재사용 입력을 빼면 평균 입력·출력은 9,296→4,884토큰으로 줄었고, 최종 답 제출 때 앞선 풀이를 다시 읽는 비용을 전부 세면 9,346→9,911토큰으로 늘었습니다. 실제 속도 비교에는 별도의 시간 측정이 필요합니다.

## 선행 연구와 남은 질문

IneqMath는 대칭이라는 이유만으로 모든 변수가 같은 곳에서 극값을 얻는다고 판단한 모델 사례를 이미 보고했습니다. LIPS는 반례를 찾아 부등식 증명 후보를 검산합니다. 이번 결과에서 더 좁혀 물을 부분은 **모델이 스스로 계산한 허용점이 나중의 후보를 반박하는 순간을 포착해, 답 소실을 막을 수 있는가**입니다. 이 가설을 시험하려면 독립 문항에서 해당 행동이 충분히 재현되어야 하며, 같은 비용의 일반 검산과 원래 맞던 풀이에서의 손실도 함께 비교해야 합니다. 독립 오류 사례 네 문항이라는 사전 조건에 도달하지 않아 대칭 가정 개입 실험을 보류했습니다.
