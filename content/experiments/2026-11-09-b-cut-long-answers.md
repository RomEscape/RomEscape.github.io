## 한 줄 요약

답이 길어지면 끊어 버리는 규칙 두 가지를 계산했습니다. **끊고 다시 뽑으면 토큰이 오히려 1.34–1.37배로 늘어 실패했습니다.** 끊고 짧게 답하는 모델(Base)로 바꾸면 12,000토큰 상한에서 정답률을 거의 지키며 토큰이 25% 줄었습니다. 하지만 미리 정한 기준에는 못 미쳐 방법으로 내세우지 않고, 앞으로 새 방법이 넘어야 할 **기준선**으로 씁니다.

## 왜 궁금했나

[전체 점검](2026-11-09-a-diagnosis.html)에서 가장 긴 답 약 10%가 토큰의 절반을 쓰고, 그 답의 정답률은 15–22%뿐이라는 것을 봤습니다. 이렇게 꼬리가 긴 분포에서는 "일정 길이를 넘으면 버리고 다시 시작"하는 방법이 이론적으로 유리합니다. 논리 문제 풀이 프로그램(SAT 해결기)에서 널리 쓰는 기법입니다. 추론 모델에도 통하는지, 저장된 답으로 값싸게 계산해 보았습니다.

|---|---|---|

| Base | 추가 학습을 하지 않은 원래 모델. 짧게 답합니다 | 문항 239에서 평균 1,354토큰 |

| QFFT | 문제를 지우고 긴 풀이만 학습한 모델(논문 방법) | 평균 4,630토큰 |

## 어떻게 계산했나

새로 답을 만들지 않았습니다. MATH500 문제 500개에 모델마다 16번씩 답하게 한 저장 기록을 씁니다. 각 문제에서 16개 답의 길이와 정답 여부를 "이 모델이 이 문제를 풀 때 나올 수 있는 답의 분포"로 봅니다.

1. **재시작:** 답이 상한 안에서 끝나면 그 답을 받습니다. 넘으면 상한만큼의 토큰을 버린 것으로 치고 다시 뽑습니다. 주 규칙은 상한 8,000토큰으로 2번 시도하고, 3번째는 상한 없이 끝까지 쓰게 합니다.
2. **Base 대체:** 답이 상한 안에서 끝나면 그 답을 받습니다. 넘으면 상한만큼 버리고, Base의 평균 토큰을 더하며, 정답 여부는 그 문제에서 Base가 맞힌 비율로 칩니다.
3. 두 규칙 모두 정답률과 토큰의 기댓값을 식으로 정확히 계산합니다. 몬테카를로 모의(무작위로 20만 번 뽑기)로 계산이 맞는지 확인했습니다.

**결과를 보기 전에 정한 기준.** A2와 QFFT 둘 다 정답률 차이 −0.5%p 이상(95% 구간 하한은 −2%p 이상)이고, 토큰 비 0.8배 이하이면 "후보"입니다.

실제 문항 두 개로 계산해 봅니다. 숫자는 답의 토큰 수이고 O는 정답, X는 오답입니다.

**문항 239(항상 긴 문항).** 네 직선으로 둘러싸인 두 평행사변형의 넓이가 18과 72일 때 $a+b+c+d$의 최솟값을 구하는 문제이고, 정답은 16입니다.

| 모델 | 16개 답을 짧은 순으로 | 맞힌 횟수 | 평균 토큰 |
|---|---|---:|---:|
| A2 | 4,800 O / 6,832 X / 7,445 O / 10,954 X / 12,469 X / 13,488 O / 13,785 X / 18,607 X / 19,241 X / 22,634 X / 25,228 X / 28,033 X / 31,998 X / 32,000 X / 32,000 X / 32,000 X | 3 | 19,469 |
| Base | 948 X / 1,009 O / 1,078 X / 1,082 X / 1,090 X / 1,098 O / 1,106 O / 1,128 O / 1,282 X / 1,284 X / 1,299 O / 1,576 X / 1,590 O / 1,858 X / 1,985 X / 2,260 O | 7 | 1,354 |

8,000토큰 안에 끝나는 A2 답은 16개 중 3개(4,800, 6,832, 7,445)이고 그중 2개가 정답입니다.

- **재시작 계산.** 한 번 시도의 평균 비용은 (4,800 + 6,832 + 7,445 + 8,000 × 13) ÷ 16 = 7,692토큰입니다. 13/16 확률로 끊기므로 두 번째 시도까지 평균 7,692 + 0.81 × 7,692 = 13,942토큰을 씁니다. 두 번 다 끊길 확률은 (13/16)² = 0.66이고, 그때 상한 없이 평균 19,469토큰을 더 씁니다. 합계는 **26,795토큰**으로, 개입 없는 생성 19,469토큰의 **1.38배**입니다. 다시 뽑아도 대부분 또 길기 때문입니다.
- **Base 대체 계산.** 3개는 그대로 받습니다. 끊긴 13개는 8,000 + 1,354토큰을 쓰고 Base 정답률 7/16을 받습니다. 평균 토큰은 (19,077 + 13 × 9,354) ÷ 16 = **8,793토큰**, 기대 정답률은 (2 + 13 × 7/16) ÷ 16 = **48.0%** 입니다. 개입 없는 생성은 18.8%입니다. 이 문제에서는 Base가 우연히 더 잘 맞혔습니다.

**문항 490(섞인 문항).** 서로 다른 정수 근을 가진 정수 계수 다항식에서 최고차 계수가 2, 상수항이 66일 때 $\lvert a_{n-1}\rvert$의 최솟값을 구하는 문제이고, 정답은 14입니다.

| 모델 | 16개 답을 짧은 순으로 | 맞힌 횟수 | 평균 토큰 |
|---|---|---:|---:|
| A2 | 2,858 X / 4,930 X / 5,567 X / 5,667 X / 5,884 X / 6,917 X / 7,228 X / 7,509 X / 9,354 O / 9,669 O / 9,878 X / 9,897 X / 11,210 X / 14,231 O / 32,000 X / 32,000 X | 3 | 10,924 |
| Base | 692–1,330토큰, 16개 중 4개 정답 | 4 | 918 |

이 문제는 맞힌 답 3개가 모두 8,000토큰을 넘습니다. 8,000토큰에서 끊으면 Base 대체의 기대 정답률은 (0 + 8 × 4/16) ÷ 16 = **12.5%** 로 개입 없는 생성 18.8%보다 떨어지고, 토큰은 7,369로 0.67배가 됩니다. 재시작은 맞힌 답이 8,000토큰 안에 하나도 없어 3번째 시도에서만 맞힐 수 있으므로 기대 정답률 4.7%, 토큰 13,096입니다. **토큰을 줄이는 대가는 이런 문제에서 나옵니다.**

## 결과 1: 재시작은 토큰이 늘어난다

칸은 "정답률, 평균 토큰"입니다.

|---|---|---|---|---:|
| SFT | 79.7%, 6,576 | 81.4%, 9,027 | +1.71%p [+1.29, +2.14] | 1.37 |
| A2 | 80.3%, 4,587 | 81.3%, 6,220 | +0.97%p [+0.58, +1.38] | 1.36 |
| A2-RAM96 | 81.2%, 4,527 | 82.4%, 6,121 | +1.22%p [+0.84, +1.60] | 1.35 |

정답률은 조금 오르지만 토큰이 늘어서 **기준 미달**입니다. 상한과 시도 횟수를 바꾼 17개 설정 모두에서 A2, QFFT의 토큰 비는 1.08배 이상이었습니다.

**왜 안 되나.** 재시작은 같은 문제에서 운에 따라 길이가 달라질 때 듣습니다. 실제로는 답 길이(로그) 차이의 **80–85%가 문제 자체의 차이**입니다. 문항 239처럼 항상 긴 문제는 다시 뽑아도 또 깁니다.

| GSM8K(1,319문항) | QFFT | 86.1%, 831 | +0.06%p [+0.02, +0.11] | 0.98 | 0% |

S1.1-A2의 토큰 비가 0.82배로 기준 0.8배를 조금 넘어 **"재현 안 됨"** 입니다. 기준을 바꿔서 통과시키지 않았습니다. 다만 정답률은 거의 그대로입니다. AIME25는 문항이 적어 참고만 합니다. GSM8K는 쉬운 문제 위주라 긴 답 자체가 드뭅니다.

## 그래서 무슨 뜻인가

- 재시작은 추론 모델의 긴 답을 줄이는 도구가 아닙니다. 긴 답은 운이 아니라 문제의 성격에서 나오기 때문입니다.
- 끊고 짧게 답하는 규칙은 토큰을 줄이는 대신 항상 긴 문제의 정답률을 조금 내줍니다. 12,000토큰 언저리에서는 전체 정답률이 거의 변하지 않습니다.
- 이 규칙은 단순합니다. 그래서 앞으로 어떤 새 방법이든 **이 기준선보다 나아야** 의미가 있습니다. `Wait` 금지(토큰 0.91배)는 이 단순한 규칙보다 덜 줄였습니다.

## 한계

- 결과를 본 뒤 설계했으므로(가장 긴 답 표를 먼저 봄) **효능 주장이 아닙니다.**
- 문제마다 16개 표본의 분포로 계산합니다. 드문 경우는 추정이 거칠습니다.
- 실제 서빙에서의 대기 시간, 두 번째 모델을 띄우는 비용은 세지 않았습니다.
- MATH500은 여러 번 쓴 자료입니다.

## 다음에 할 일

- 재시작은 새 착안이 없으면 더 하지 않습니다.
- 상한 + Base 대체는 비교 기준선으로 씁니다. 앞으로 큰 평가에서는 같은 표본에서 이 기준선을 함께 계산합니다.
- 항상 긴 문제를 **답을 쓰기 전에** 가려낼 수 있으면 끊기 전에 쓰는 토큰까지 아낄 수 있습니다. 사후 계산의 상한은 토큰 0.53배입니다. 다음 계산에서 이 기준선을 넘는지 봅니다.
