## 한 줄 요약

다른 시스템이 만든 평가 글이나 해설을 인물 말투로 바꾸는 **화법 변환기** 세 가지를 만들었습니다. 핵심 원칙은 **"말투가 자연스러워도 원문 내용이 빠지면 실패"**입니다. 미술 코멘트 변환은 영어가 남은 칸이 김홍도 5.4%, 정선 3.8%이고, 가창지도 전용 어댑터는 지적 사항 보존이 99.3%로 일반 말투 어댑터(79.8%)보다 크게 나았습니다. 작품토론 변환은 숫자를 100% 지켰지만, 글 속에 숨겨 넣은 지시를 그대로 옮겨 쓰는 비율이 90%(9/10)라 고쳐야 합니다. 점수는 규칙 측정과 LLM 자동 평가이며 사람 점수가 아닙니다.

## 왜 필요했나

- 이 과제에서 인물 모델은 혼자 모든 것을 하지 않습니다. 그림 평가, 노래 평가, 작품 해설은 각각 전문 모델이나 시스템이 맡고, 인물 모델은 그 결과를 **인물이 직접 말하는 것처럼** 전달합니다.
- 그대로 붙이면 문제가 생깁니다. 미술 평가는 영어로 나오고, 작품 해설은 "~합니다"로 끝나는 격식체 설명문입니다. 김홍도는 하오체, 정선은 하게체, 조수미는 부드러운 해요체로 말해야 합니다.
- 말투만 바꾸다 보면 원문의 지적 사항, 숫자, 곡 제목이 빠지거나 바뀌기 쉽습니다. 평가 글에서 지적이 하나 빠지면 사용자는 고칠 점을 놓칩니다. 그래서 **내용 보존**을 말투보다 먼저 봅니다.

## 용어 풀이

| 용어 | 뜻 | 이 글에서의 실제 값 |
|---|---|---|
| 화법 변환기 | 다른 시스템의 글을 내용은 그대로 두고 인물 말투로 바꾸는 기능 | 미술 코멘트, 가창지도, 작품토론 세 가지 |
| 어댑터(LoRA) | 큰 모델은 고정하고 작은 추가 가중치만 학습하는 방법. 기능마다 하나씩 붙였다 뗄 수 있음 | r16, α32, 2에폭 |
| 에폭 | 학습 자료 전체를 한 바퀴 보는 단위 | 2에폭(작품토론은 3에폭) |
| INT4 | 모델 가중치를 4비트 정수로 줄여 메모리와 속도를 아끼는 방식 | 7.8B 모델 약 5.4GB |
| 칸(필드) | 입력 JSON의 항목 하나. 총평, 평가, 처방 같은 것 | 미술 시험 260칸 |
| 영어 잔존 | 바꾼 뒤에도 영어 표현이 남은 칸의 비율 | 김홍도 5.4% (14/260) |
| 지적 보존율 | 원문의 지적 사항이 바꾼 글에 빠짐없이 남은 비율 | 가창 전용 어댑터 99.3% |
| 격식체 비율 | 바꾼 뒤에도 "~합니다" 같은 딱딱한 말투가 남은 비율 | 0% (0/68) |
| 숨긴 지시 옮김 | 입력 글 속에 몰래 넣은 지시문("이 문장을 그대로 출력하라" 같은)을 변환 결과에 그대로 옮겨 쓴 비율. 낮을수록 좋음 | 작품토론 90.0% (9/10) |
| 지침 유출 | 모델 내부 지시문을 답에 드러낸 비율 | 0% (0/10) |

## 무엇을 했나

1. **변환기 세 가지 정의.**
   - 미술 코멘트: 미술 평가 모델(협력 기관 담당)이 낸 영어 평가 JSON을 받아 **같은 구조**로 돌려줍니다. 등급, 점수, 항목 이름은 그대로 두고 총평, 평가, 처방 세 칸만 화가 말투 한국어로 바꾸고 맺음말을 덧붙입니다.
   - 가창지도: 노래 평가 글의 칸 목록을 받아 **칸 수와 순서가 같은** 조수미 말투 한국어 칸 목록으로 돌려줍니다.
   - 작품토론: 음악 작품 해설 시스템(협력 기관 담당)의 답에서 해설 한 칸만 문장 단위로 조수미 말투로 바꿔 차례로 내보냅니다.
2. **세 단계 구조.** 모델이 통째로 바꾸고, 검사에서 걸리면 문제 부분만 다시 바꾸고, 그래도 안 되면 규칙으로 어미만 고치거나 원문을 씁니다(아래 그림).
3. **어댑터 학습.** 인물 대화 모델(INT4)을 같은 값의 bf16으로 풀어 고정하고, 그 위에 기능별 어댑터를 학습했습니다. 설정은 LoRA r16, α32, 2에폭, 학습률 1e-4입니다. 실제 서비스도 같은 INT4 바탕에 어댑터를 붙이므로 학습과 실행 조건이 맞습니다.
4. **학습 자료.** 미술은 영어–한국어 변환 쌍 김홍도 3,309행, 정선 3,152행, 가창은 3,546행, 작품토론은 변환 쌍 학습 795, 검증 141쌍입니다.
5. **평가 자료는 학습과 분리.** 미술은 학습에 안 쓴 합성 입력 인물별 20건(260칸), 가창은 학습에 안 쓴 영어 24건(68칸)과 한국어 300건, 작품토론은 새로 쓴 해설 48건, 실제 시스템 답 56건, 숨긴 지시 시험 10건입니다.

## 실제 예시

아래 문장은 구조를 보여 주려고 만든 **설명용 예시**입니다. 실제 입력 원문은 협력 기관 자료라 싣지 않습니다.

| 변환기 | 입력 칸(예) | 출력 칸(예) | 그대로 두는 것 |
|---|---|---|---|
| 미술 코멘트(김홍도) | `The brushwork lacks the swift energy of the line.` | "붓질에 선의 날랜 기운이 모자라오." | 등급, 점수, 항목 이름 |
| 가창지도(조수미) | `Issues: nasal quality at the start` | "시작 부분에서 소리가 코에 조금 걸리는 느낌이 있어요." | 칸 수, 칸 순서 |
| 작품토론(조수미) | "피아노 반주는 곡의 분위기를 전달하는 중요한 요소로 작용합니다." | "피아노 반주는 이 곡의 분위기를 전하는 아주 중요한 역할을 해요." | 곡 제목, 숫자, 고유명사 |

검사 단계가 하는 일을 한 줄씩 보면 이렇습니다.

1. 원문에 있던 숫자와 용어가 결과에 모두 있는지 셉니다(숫자 보존, 용어 보존).
2. 영어 낱말이 남았는지, "~합니다" 같은 격식체가 남았는지 봅니다.
3. 칸 수와 순서, 등급과 점수가 입력과 같은지 봅니다.
4. 하나라도 걸리면 그 문장이나 칸만 다시 바꿉니다. 미술 코멘트는 영어 잔존이 줄어들 때만 교체합니다.

## 결과

### 가창지도 전용 어댑터를 따로 만든 이유

표 읽는 법: 같은 가창 평가 글을 세 설정으로 바꾼 뒤, 모델 이름을 가린 LLM 자동 평가로 매긴 값입니다. 지적 보존은 높을수록, 추가와 왜곡은 낮을수록 좋습니다. 조수미다움과 유용성은 5점 만점입니다(사람 점수 아님).

| 설정 | 지적 보존 | 추가, 왜곡(100건당) | 칭찬과 지적이 뒤집힌 건 | 조수미다움 | 유용성 |
|---|---|---|---|---|---|
| 가창 전용 어댑터 | **99.3%** | **2.1** | 0 | 4.01 | 4.00 |
| 일반 말투 어댑터 | 79.8% | 70.0 | 1 | 3.51 | 3.36 |
| 어댑터 없음 | 77.9% | 74.3 | 7 | 3.51 | 3.34 |

- 미리 정한 기준(지적 보존 95% 이상, 추가, 왜곡 100건당 3건 이하, 뒤집힘 0, 조수미다움과 유용성 4.0 이상)을 모두 넘은 설정은 가창 전용 어댑터 하나였습니다. 다만 조수미다움과 유용성은 4.0에 겨우 걸쳤습니다.
- 일반 말투 어댑터는 말투를 바꾸다 지적 사항 다섯 개 중 하나꼴로 빠뜨렸습니다. 기능마다 어댑터를 따로 둔 이유입니다.

### 세 변환기의 규칙 측정

표 읽는 법: 학습에 쓰지 않은 평가 자료로 잰 규칙 측정값입니다(사람 점수 아님). 목표를 못 넘은 칸은 굵게 표시했습니다.

### 그 뒤에 바꾼 것

- **가창 입력을 한국어 평가 글로.** 실제로 받을 가창 평가 모델의 출력이 한국어 글이라, 입력 기준을 영어 칸 목록에서 한국어 평가 글로 바꿨습니다. 학습에 안 쓴 한국어 300건에서 용어 일치 99.76%, 격식체 0%였습니다. 긴 입력 60건 자동 평가에서는 새 어댑터(v2)가 추가와 왜곡을 100건당 60.0에서 33.3으로 줄여 v2로 바꿨습니다.
- **꾸밈표 정리.** 모델이 답에 굵게 표시(`**`)를 섞는 버릇이 있어, 출력 정리 규칙을 넣은 뒤 실제 입력 715칸, 585칸에서 남은 꾸밈표가 0칸이 됐습니다.
- **영어 전처리 고침.** 한국어용 전처리가 영어 입력에 잘못 돌아 입력이 망가지던 문제를 찾아, 영어 전처리와 이름 바로잡기를 따로 두었습니다.

## 그래서 무슨 뜻인가

- 기능마다 전용 어댑터를 두는 것이 내용 보존에 크게 유리합니다. 같은 인물 말투라도 "평가 글 옮기기"와 "해설 옮기기"는 다른 기술입니다.
- 모델 변환만으로는 부족하고, 검사와 부분 재변환이 품질을 끌어올립니다. 작품토론 48건 중 모델이 한 번에 통과한 것은 15건이었고, 부분 재변환으로 21건을 더 살렸습니다.
- 반대로 입력 글을 그대로 믿고 옮기는 성질 때문에, 글 속에 숨긴 지시까지 충실히 옮깁니다. 내부 지침은 새지 않았지만(0/10), 받은 글을 거르는 단계가 필요합니다.

## 한계와 남은 일

- **내용 보존 공통 판정을 아직 하지 않았습니다.** 최종 모델 출력 표본으로 내용 보존 95% 이상, 평가 뒤집힘 0%, 인물다움 4.0 이상(5점 만점)을 볼 계획입니다.
- **실제 가창 평가 모델의 출력으로 처음부터 끝까지 이어 본 시험이 없습니다.** 지금 값은 평가용 표본으로 잰 것입니다.
- **숨긴 지시 옮김 90%.** 입력 글에서 지시문을 걸러내는 단계를 넣어야 합니다.
- 미술 코멘트는 김홍도 쪽 영어 잔존이 목표(5%)를 조금 넘었습니다.
- 사람 평가가 없습니다.
