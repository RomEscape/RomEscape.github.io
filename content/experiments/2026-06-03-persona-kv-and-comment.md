## 한 줄 요약

**프로필을 모델 안에 직접 넣는 시험(KV 내재화)**은 "고정된 사실을 기억하는 데"는 완벽했지만 처음 보는 질문에는 약해, 문서 검색(RAG)을 대신하지는 못했습니다. **가창 평가 코멘트를 조수미 말투로 바꾸는 반복 학습**은 다섯 차례 고쳐도 합격선에 못 미쳤습니다(지적 반영률 최고 0.666, 합격 0.90). 두 시험 모두 이 시기에는 서비스에 넣지 않았습니다.

## 왜 필요했나

- **KV 내재화:** 문서 검색은 질문마다 프로필 문단을 찾아 프롬프트에 붙이므로 입력이 길어지고, 검색이 빗나가면 엉뚱한 문단이 붙습니다. 프로필을 아예 모델 안에 넣어 둘 수 있다면 더 안정적일 것이라 보고 시험했습니다.
- **코멘트 변환:** 가창 지도 기능은 다른 시스템이 만든 노래 평가 코멘트를 받아 조수미가 직접 말해 주는 듯한 지도 글로 바꿔야 합니다. 말투만 바꾸고 **지적과 처방은 하나도 빠뜨리면 안 됩니다.**

## 용어 풀이

| 용어 | 뜻 | 이 글에서의 실제 값 |
|---|---|---|
| KV | 모델이 앞 글을 읽으며 층마다 만들어 두는 내부 값(Key, Value). 다음 글을 쓸 때 이 값을 참고함 | 층 32개 각각의 값 |
| 기억 토큰 | 프로필을 압축해 담는 학습 가능한 가짜 토큰 | K = 16개(4개, 1개도 비교) |
| KV 내재화 | 프로필을 기억 토큰의 KV로 압축해 두고, 답할 때 그 KV를 앞에 붙이는 방식 | 기반 모델은 고정 |
| BLEU-4, Rouge-2 | 되살린 글이 원문과 단어 묶음 단위로 얼마나 겹치는지(1이 완전 일치) | K=16에서 0.9225, 0.9278 |
| token-F1 | 답과 정답이 단어 단위로 얼마나 겹치는지(1이 완전 일치) | 학습한 사실 1.0, 처음 보는 질문 0.391 |
| 처음 보는 질문(held-out) | 학습에 쓰지 않고 따로 떼어 둔 평가 질문 | 14문항 |
| 지적 반영률 | 원래 코멘트의 지적, 처방 가운데 변환 글에 남은 비율 | 합격 0.90 이상 |
| 반복 학습 | 평가 결과를 보고 자료, 학습, 추론을 고쳐 다시 학습하는 과정 | 1~5회차 |
| QLoRA, 이어 학습 | 4비트 고정 모델에 작은 덧붙임만 학습. 앞 회차 덧붙임에서 이어서 학습 | phi-3.5-mini 바탕 |

## 무엇을 했나

### KV 내재화

1. 조수미 대화 모델(kanana 2.1B 전체 파인튜닝)을 **완전히 고정**했습니다.
2. 프로필을 480토큰 이하 조각 78개로 나눴습니다(학습 71, 검증 7).
3. 학습하는 부분은 두 가지뿐입니다. 프로필을 읽는 쪽에 붙인 작은 덧붙임(LoRA, r=16)과 기억 토큰 K개의 임베딩입니다.
4. **1단계(되살리기):** 프로필 조각을 읽혀 기억 토큰의 KV를 만들고, 고정된 모델이 그 KV만 보고 원래 조각을 다시 쓰게 학습했습니다(40에폭, 학습률 1e-3, 모델 하나에 약 6.5분).
5. **2단계(질문 답하기):** 프로필에서 뽑은 질문과 답 142개(검증 14개)로, KV를 보고 사실 질문에 답하게 이어 학습했습니다(20에폭, 학습률 5e-4, 약 4.5분).
6. KV만, 문서 검색만, 둘 다 쓴 경우를 비교했습니다.

### 가창 코멘트 변환

1. 입력은 공개 가창 평가 자료(VocalCoachBench)의 노래 평가 코멘트입니다. 평가자 한 명이 노래 하나에 지적 여러 개를 남깁니다.
2. 출력 규칙: 지적 하나에 문단 하나, 번호 붙이지 않기, 마지막 문단에서 "다시 부른다면 이렇게"라며 교정 시범 음원을 예고하기.
3. 큰 모델로 모범 변환 글을 만들고(1회차 40개 → 4회차 289개), 기존 대화 자료 200개를 섞어 말투를 잊지 않게 했습니다.
4. 앞 회차의 덧붙임에서 이어서 학습했습니다(3~5에폭, 학습률 1e-4 또는 8e-5, 최대 길이 4,096).
5. 매 회차 학습에 쓰지 않은 코멘트 20개로 평가했습니다. 합격선은 지적 반영률 0.90 이상, LLM 평가(gpt-4.1-mini, 지적의 근거 보존과 처방 보존 각각 1~10점) 7점 이상, 끝까지 쓴 비율, 이물질 없음, 인물 이탈 없음 각 1.0입니다.

## 실제 예시

코멘트 변환에서 실제로 시험한 코멘트(지적 4개)의 핵심 내용과, 변환 글에 남아야 할 처방입니다.

| 지적 | 남아야 할 처방 |
|---|---|
| 1 | 호흡이 불안해 끝음이 흔들림 → 호흡의 압력 연습 |
| 2 | 끝음이 뚝 끊김 → 비브라토, 계획적인 끝음 처리 |
| 3 | 박자가 흔들림 → 메트로놈 연습 |
| 4 | 강약이 단조로움 → 전조, 완급 조절, 다이내믹 |

실제 출력의 문제(요약):

| 모델 | 무엇이 나왔나 |
|---|---|
| 코멘트 학습 전 바탕 모델 | 감정 표시 뒤 다른 문자가 섞여 무너지고, 내부 메타 문구가 노출됨 |
| 4회차(가장 좋은 판) | 금지한 "리뷰 1에 대해:" 라벨을 붙이고, 수십 자 뒤 알아볼 수 없는 글로 무너짐 |
| EXAONE 2.4B 대화 모델 | "사용자님" 호칭을 쓰고, 다음 사용자 차례를 지어내려다 멈춤 |

## 결과

### 1. KV 내재화: 되살리기

표 읽는 법: 프로필 78조각 전체를 기억 토큰의 KV만 보고 다시 썼을 때 원문과 겹친 정도입니다(1이 완전 일치, 규칙 측정).

| 기억 토큰 수 | BLEU-4 | Rouge-2 |
|---|---|---|
| K = 16 | 0.9225 | 0.9278 |
| K = 4 | 0.8846 | 0.8910 |
| K = 1 | 0.8552 | 0.8627 |

300토큰 안팎의 한국어 문단은 기억 토큰 16개면 사실상 원문 그대로 되살아났습니다.

### 2. KV 내재화: 사실 질문

표 읽는 법: 왼쪽은 학습에 쓴 조각에서 낸 질문, 오른쪽은 처음 보는 질문입니다. 앞 숫자는 token-F1, 뒤 숫자는 판정 점수(자체 구현, 1이 만점)입니다.

| 방식 | 학습한 조각(30문항) | 처음 보는 질문(14문항) |
|---|---|---|
| KV만 | 1.0 / 1.0 | 0.391 / 0.214 |
| 문서 검색만 | — | 0.336 / 0.857 |
| KV + 문서 검색 | — | 0.447 / 0.929 |

### 3. 코멘트 변환 반복 학습

표 읽는 법: 회차마다 학습에 쓴 모범 변환 글 수와, 학습에 쓰지 않은 코멘트 20개에서 잰 값입니다. LLM 평가는 gpt-4.1-mini가 1~10점으로 매긴 값입니다(사람 점수 아님).

| 회차 | 모범 변환 글 | 지적 반영률(합격 0.90) | LLM 평가: 근거 / 처방(합격 7) | 끝까지 씀(합격 1.0) |
|---|---|---|---|---|
| 1 | 40 | 0.51 | 4.07 / 3.27 | 0.67 |
| 2 | 40(+형식 맞춤) | 0.584 | 5.5 / 4.1 | 0.35 |
| 3 | 163 | 0.519 | 5.55 / 4.85 | 0.50 |
| 4 | 289 | **0.666** | **5.9 / 5.35** | 0.65 |
| 5 | 문단 구조로 다시 만든 76 + 4회차 글 중 반영률 높은 것 | 0.46 | 2.95 / 2.15 | 0.25 |

4회차가 가장 좋았지만 어느 항목도 합격선에 닿지 않았습니다. 4회차에 다시 시도(빠진 지적을 알려 주고 다시 쓰게 함)를 붙여도 0.48로 오히려 낮았습니다. 그리고 **실제 지적 4개짜리 코멘트 하나로 시험하자, 바탕 모델, 4회차, EXAONE 2.4B 모두 지적을 하나도 옮기지 못했고 끝까지 쓰지도 못했습니다.**

## 그래서 무슨 뜻인가

- **KV 내재화는 "고정된 사실을 외우는 일"에는 충분했습니다.** 학습한 사실 질문은 모두 맞혔습니다. 그러나 사용자의 질문은 미리 알 수 없으므로, 문서 검색을 대신할 수는 없었고 함께 쓰는 쪽이 가장 나았습니다. 서비스에 넣으려면 추론 경로를 크게 바꿔야 해 이 시기에는 따로 떼어 둔 시험으로 남겼습니다.
- **코멘트 변환이 실패한 원인은 자료 양보다 구조였습니다.** 모범 글은 지적을 문단으로 잘 나눴지만, 작은 바탕 모델은 대화 습관(감정 표시, 상대 차례 지어내기)을 버리지 못했습니다. 평가 세트의 점수(0.666)와 실제 코멘트 하나의 결과(0)가 크게 달랐던 것도, 평가 세트만 보고 판단하면 안 된다는 경고였습니다.
- 10월에는 바탕을 EXAONE 7.8B로 바꾸고, 가창 지도 전용 덧붙임을 학습하고, 코멘트를 300자 조각으로 나눠 바꾼 뒤 검사하는 방식으로 다시 풀었습니다. 그때 지적 보존율이 99.3%가 되었습니다([화법 변환기 기록](2026-11-03-persona-speech-converter.html)).

## 한계와 남은 일

- KV 시험의 처음 보는 질문은 14개뿐입니다.
- KV 시험의 판정 점수는 자체 구현한 지표라 다른 연구의 값과 비교할 수 없습니다.
- 코멘트 변환의 LLM 평가는 gpt-4.1-mini 한 모델로만 매겼습니다.
- KV 내재화는 이후 다시 시험하지 않았습니다.
