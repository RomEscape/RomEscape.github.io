## 한 줄 요약

2.4B 모델은 7.8B보다 **응답이 약 40% 빠르지만**, 같은 대화 안에서 **앞 답의 문장을 그대로 다시 쓰는 버릇**이 강했습니다(대화 300턴 기준 2.4B 2~28%, 7.8B 0~1%). 학습 자료의 반복은 0.1~0.3%뿐이어서, 원인은 자료가 아니라 작은 기반 모델로 보았습니다. 2.4B의 **모든 에폭**을 어느 모델 답인지 가린 LLM 자동 평가로 비교해 인물별 시험용 모델을 고르고, 반복 문장 차단 규칙을 붙였습니다. 뒤에 **차단 규칙이 기존 반복 지표를 가려 0%처럼 보이게 만든다**는 것을 알고, 문장 일부의 반복까지 잡는 새 지표로 다시 쟀습니다. 같은 대화 안에서 앞 답의 8글자 조각이 이번 답을 덮는 비율이 2.4B 17.14%, 7.8B 3.60%, 학습 자료 3.77%였습니다. **서비스 기본 모델은 세 인물 모두 7.8B**로 정했습니다.

## 왜 필요했나

- 응답시간 기준(0.5초)을 넉넉히 맞추려면 작은 모델이 유리합니다. 하지만 작은 모델이 대화 품질을 얼마나 잃는지 숫자로 알아야 했습니다.
- 학습은 10에폭까지 하는데, 어느 에폭이 가장 좋은지는 학습 손실만으로 알 수 없습니다. 모든 에폭을 같은 조건에서 직접 비교해야 했습니다.
- 사용자들이 "2.4B는 같은 말을 자꾸 반복한다"고 느꼈습니다. 이것이 사실인지, 원인이 자료인지 모델인지 가려야 했습니다.

## 용어 풀이

| 용어 | 뜻 | 이 글에서의 실제 값 |
|---|---|---|
| 7.8B, 2.4B | 모델의 매개변수 수(78억, 24억 개) | 기반 모델 EXAONE 3.5 7.8B, 2.4B |
| 에폭(ep) | 학습 자료 전체를 한 바퀴 도는 단위. ep5는 5바퀴 학습한 모델 | 2.4B는 ep2~ep10을 저장해 모두 평가 |
| LLM 자동 평가 | 대형 언어 모델이 정해진 기준(루브릭)으로 답을 채점하는 것. 사람 점수가 아님 | 이 글의 품질 점수 전부 |
| 블라인드 평가 | 평가하는 쪽이 어느 모델의 답인지 모르게 이름을 가리는 것 | 모델 이름을 지우고 묶음으로 평가 |
| 종합 점수 | 100 × 평균(모든 대화 8항목을 0~1로 바꾼 값, 한 턴 5항목을 0~1로 바꾼 값, 시험지 확인 항목 통과율) | 김홍도 2.4B ep5 74.8 |
| 같은 답 반복 | 같은 대화 안에서 앞 답과 같거나 거의 같은 문장을 다시 쓰는 것 | 2.4B 2~28%, 7.8B 0~1% |
| 3-gram 자카드 유사도 | 두 문장을 세 글자씩 잘라 겹치는 조각의 비율을 잰 값. 1이면 같은 문장 | 0.8 이상이면 같은 문장으로 봄 |
| 반복 문장 차단 규칙 | 실행 중에 앞 답과 거의 같은 문장을 내보내지 않는 코드 | 12자 이상, 3-gram 자카드 0.8 이상이면 막음 |
| 8자 조각 덮임 | 이번 답 글자 가운데, 같은 대화 앞 답에 있던 8글자 조각으로 덮이는 글자의 비율(공백과 문장부호는 빼고 셈) | 2.4B ep4 17.14% |
| 95% 구간 | 문항을 다시 뽑아 계산했을 때 값이 있을 만한 범위. 두 모델 차이의 구간이 0을 품으면 차이가 있다고 말하지 않음 | 상위 에폭끼리의 차이는 0을 품음 |

## 무엇을 했나

1. **평가 묶음 만들기.** 인물마다 한 턴 질문 110개, T-002 공식 10턴 대화 10건, 10턴 시험 대화 20건을 모았습니다. 같은 묶음을 일부 다시 넣어 평가가 얼마나 흔들리는지도 쟀습니다. 모두 93개 묶음입니다.
2. **블라인드 평가.** 7.8B 공식 모델과 2.4B 모든 에폭의 답을 모델 이름을 가린 채 섞어 LLM 자동 평가에 넘겼습니다. 평가는 T-002 8항목(1~7점), 한 턴 5항목(1~5점), 100답당 사실 오류, 대화당 큰 문제 수, 외국어로 나간 답 비율을 함께 매겼습니다.
3. **평가 흔들림 확인.** 같은 묶음을 다시 평가하면 점수가 약 0.16 달라졌고, 에폭 순위의 상관은 약 0.85였습니다. 그래서 상위 에폭 사이의 작은 차이는 차이로 보지 않았습니다.
4. **반복 원인 측정.** 같은 패키지와 설정으로 대화 300턴을 만들어 같은 답 반복을 셌습니다. 학습 자료 안의 반복도 같은 방식으로 셌습니다.
5. **반복 문장 차단 규칙.** 같은 대화의 앞 답과 같거나 3-gram 자카드 0.8 이상(12자 이상)인 문장은 내보내지 않고, 모든 문장이 걸리면 후보 2개를 다시 만들게 했습니다. 사용자가 "다시 말해 달라"고 하면 비교하지 않습니다. 공인 시험용으로 고정한 패키지에는 넣지 않았습니다.
6. **지표 다시 만들기(11-04).** 새 2.4B 모델의 반복이 0.2% 이하로 나오자 의심이 들었습니다. 평가 답이 이미 차단 규칙을 거쳤고, 잰 지표가 차단 규칙과 같은 기준이라 낮게 나오는 것이 당연했습니다. 그래서 **문장 전체가 아니라 8글자 조각 단위로** 반복을 재는 지표를 새로 만들어 다시 쟀습니다.
7. **7.8B 에폭 판정.** 김홍도 7.8B를 새 자료로 다시 학습한 뒤, 에폭 3~7과 공식 모델을 같은 블라인드 방식으로 비교했습니다. 결과를 보기 전에 "위험성 3%p, 외국어 3%p, 상세 평가 0.2점 안에서 나빠지지 않으면 ep4"라는 규칙을 먼저 적어 두었습니다.

## 실제 예시

8자 조각 덮임을 한 번 계산해 보겠습니다(설명용 예시 문장입니다).

- 앞 답: "강가에 앉아 물소리를 들으며 붓을 들었소. 그날 바람이 참 맑았지."
- 이번 답: "그때도 강가에 앉아 물소리를 들으며 먹을 갈았소."

1. 공백과 문장부호를 빼면 이번 답은 `그때도강가에앉아물소리를들으며먹을갈았소`, 20글자입니다.
2. 이번 답을 8글자씩 밀며 잘라, 앞 답에도 있는 조각을 찾습니다. `강가에앉아물소리`부터 `물소리를들으며` 앞까지 이어지는 조각들이 앞 답에 있습니다.
3. 그 조각들이 덮는 글자는 `강가에앉아물소리를들으며` 12글자입니다.
4. 덮임 = 12 / 20 = **60.0%**. 문장 전체가 같지는 않아서 3-gram 자카드 기준의 차단 규칙에는 걸리지 않을 수 있지만, 이 지표에는 잡힙니다.

## 결과

표 읽는 법: 세 인물의 7.8B 공식 모델과 2.4B 가운데 고른 에폭을 비교합니다. 종합 점수는 100점 만점, T-002 8항목은 7점 만점입니다. 응답시간은 같은 표에 함께 잰 값입니다. 모두 LLM 자동 평가(블라인드, 사람 점수 아님)입니다.

| 인물 | 모델 | 종합 | T-002 8항목 | 사실 오류(100답당) | 대화당 큰 문제 | 외국어 답 | 응답시간 |
|---|---|---|---|---|---|---|---|
| 김홍도 | 7.8B 공식 | 78.7 | 5.79 | 4.5 | 0.43 | 3.3% | 0.496초 |
| 김홍도 | 2.4B ep5(종합 1위) | 74.8 | 5.38 | 5.5 | 1.13 | 1.1% | 0.273초 |
| 정선 | 7.8B 공식 | 80.9 | 5.67 | 4.5 | 0.37 | 2.2% | 0.486초 |
| 정선 | 2.4B ep6(고름) | 69.8 | 4.90 | 11.8 | 1.03 | 0.0% | 0.284초 |
| 정선 | 2.4B ep3(종합 1위) | 70.3 | 4.83 | 7.3 | 1.20 | 0.0% | 0.355초 |
| 조수미 | 7.8B 공식 | 62.1 | 4.80 | 12.7 | 1.93 | 12.1% | 0.495초 |
| 조수미 | 2.4B ep2(종합 1위) | 63.3 | 4.69 | 11.8 | 1.73 | 12.1% | 0.263초 |

- 김홍도는 종합 1위인 ep5를 골랐습니다.
- 정선은 ep3, ep4, ep5, ep6이 69.5~70.3으로 통계상 같아서, 대화당 큰 문제가 가장 적은 ep6을 골랐습니다(대안 ep4).
- 조수미는 ep2를 골랐습니다(대안 ep6). ep7~ep10은 확실히 나빴습니다.
- 상위 에폭끼리의 차이는 95% 구간이 0을 품었습니다.

표 읽는 법: 같은 대화 안에서 앞 답과 같은(거의 같은) 문장을 다시 쓴 비율입니다. 규칙 측정입니다.

| 대상 | 같은 답 반복 |
|---|---|
| 학습 자료(7.8B용, 2.4B용 같음) | 0.1~0.3% |
| 7.8B 모델, 대화 300턴 | 0~1%(조수미만 7%) |
| 2.4B 모델, 대화 300턴 | 2~28% |

표 읽는 법: 반복 문장 차단 규칙을 켠 상태에서 잰 8자 조각 덮임입니다. 값이 학습 자료(맨 위 줄)에 가까울수록 자료 수준의 반복입니다. 규칙 측정입니다.

표 읽는 법: 김홍도 7.8B를 새 자료로 다시 학습한 뒤 공식 모델과 비교한 블라인드 LLM 자동 평가입니다.

| 지표 | 새 7.8B ep4 | 7.8B 공식 |
|---|---|---|
| 종합(100점) | 81.5 | 76.9 |
| 모든 대화 8항목(7점) | 5.58 | 5.09 |
| 대화당 큰 문제 | 0.42 | 0.86 |
| 외국어 답 | 2.2% | 2.2% |

- 다른 에폭의 종합은 ep5 78.7, ep6 78.4, ep3 77.1, ep7 75.8이었습니다. 미리 정한 규칙에 따라 ep4를 바탕 모델로 정했습니다.
- 같은 대화끼리 짝지은 8항목 차이는 +0.48(95% 구간 0.21 ~ 0.74)이었습니다.
- 다만 위기 발화 대응 통과율은 새 모델이 공식 모델보다 낮았습니다(46% 대 61%). 이 부분은 안전 자료 보강 과제로 넘겼습니다.

## 그래서 무슨 뜻인가

- **작은 모델의 대가는 반복과 사실 오류입니다.** 2.4B는 빠르지만 같은 대화 안에서 앞 답의 문장과 구절을 다시 쓰고, 정선처럼 사실 오류가 크게 늘기도 했습니다. 학습 자료에는 그런 반복이 거의 없으므로 자료를 고쳐서 풀 문제가 아닙니다.
- **에폭은 모두 재 봐야 합니다.** 정선은 손실이 가장 낮은 에폭(ep3)과 고른 에폭(ep6)이 달랐고, 조수미는 ep2가 가장 좋고 ep7 이후는 나빠졌습니다.
- **고치는 장치가 지표를 가릴 수 있습니다.** 반복 문장 차단 규칙을 붙인 뒤 같은 기준의 지표로 재면 반복이 사라진 것처럼 보입니다. 평가 지표는 고치는 장치와 다른 기준으로 만들어야 합니다.
- 그래서 서비스용 기본 대화 모델은 세 인물 모두 7.8B로 정했고, 2.4B는 응답시간 시험용으로만 씁니다.

## 한계와 남은 일

- 품질 점수는 모두 LLM 자동 평가입니다. 같은 묶음을 다시 평가하면 약 0.16 흔들리므로, 이보다 작은 차이는 읽지 않습니다.
- 반복 문장 차단 규칙은 문장 전체가 거의 같을 때만 막습니다. 8자 조각 단위의 구절 반복은 남습니다.
- 2.4B의 반복은 에폭이 늘수록 대체로 줄었지만, 사실 오류와 맞바꿔지는 경우가 있어 한 지표로 에폭을 고를 수 없습니다.
- 7.8B 새 모델의 위기 발화 대응이 공식 모델보다 낮은 점은 안전 자료로 보강하고 다시 평가해야 합니다.
