## 한 줄 요약

인물 대화 모델을 학습시키려면 그 인물이 실제로 말하는 듯한 대화가 많이 필요합니다. 그런 대화는 따로 없으므로, 인물 소개 글(프로필)에서 **장면을 만들고, 장면에서 대화를 만드는** 방식으로 학습 자료를 만들었습니다. 조수미는 77문단에서 1,540개 대화를 얻었고, 김홍도와 정선도 같은 방식으로 1,400개, 1,600개를 만들었습니다. 만드는 도중 생성 모델이 스스로 세운 계획 글이 대화 속에 섞여 들어가거나, 필터가 정상 장면까지 버리는 문제를 찾아 고쳤습니다. 가장 큰 교훈은 **프로필 사실이 대화에 거의 나오지 않으면 모델이 사실을 지어낸다**는 것이었습니다.

## 왜 필요했나

- 이 프로젝트는 실존 예술가 세 사람(소프라노 조수미, 조선 화가 김홍도와 정선)처럼 말하는 한국어 대화 모델을 만듭니다.
- 모델이 인물의 말투, 생각, 경험을 익히려면 "그 인물이 등장하는 대화"로 학습해야 합니다.
- 실제 인터뷰 기록은 양이 적고 형식도 제각각입니다. 그래서 Character-LLM(EMNLP 2023) 논문처럼 **프로필에서 대화를 자동으로 만드는** 방식을 한국어에 맞게 옮겼습니다.

## 용어 풀이

| 용어 | 뜻 | 이 글에서의 실제 값 |
|---|---|---|
| 프로필 | 인물의 생애, 작품, 성격을 정리한 글 | 조수미 77문단, 김홍도 70문단, 정선 80문단 |
| 장면 | 대화가 벌어지는 장소와 상황 설명 | 문단 하나에 장면 20개, 조수미 1,540개 |
| 학습 대화 | 장면 안에서 인물과 상대가 주고받는 대화 | 조수미 1,540개. 1월 판은 대화당 평균 약 50턴의 긴 대화 |
| 턴 | 대화에서 한 사람이 한 번 말한 것 | 조수미 1월 26일 판 전체 76,320턴 |
| 파싱 | 생성 모델이 쓴 글에서 필요한 칸(장소, 배경, 대사)을 읽어 내는 일 | 장면 파싱 성공률 18.11% → 99.93% |
| 속생각 글 | 생각하는 모델(Thinking 모델)이 답을 쓰기 전에 혼자 세우는 계획 글 | "Let's proceed." 같은 영어 계획문 |
| 미세조정(SFT) | 이미 만들어진 모델에 정답 대화를 보여 주어 말하는 습관을 바꾸는 학습 | 이 자료로 조수미 모델을 학습 |
| 문서 검색(RAG) | 질문과 관련된 프로필 문단을 찾아 답을 쓰기 전에 모델에게 보여 주는 방식 | 질문마다 프로필 문단 3개를 붙임 |
| 할루시네이션 | 모델이 사실이 아닌 내용을 그럴듯하게 지어내는 것 | 틀린 출생 연도를 말함 |
| LLM 자동 평가 | 다른 대형 언어 모델이 답을 읽고 점수를 매기는 방식(사람 점수 아님) | 1~7점 척도 |

## 무엇을 했나

1. **프로필 다듬기.** 같은 사건이 여러 문단에 흩어져 있고 장면에 쓸 구체적인 묘사가 부족해, 조수미 프로필을 77문단으로 다시 정리했습니다(01-18).
2. **장면 만들기.** 문단마다 장소와 상황을 담은 장면 20개를 만들게 했습니다. 77문단 × 20장면 = 1,540장면입니다. 장면 생성 모델은 처음 Qwen3-14B였다가 gpt-oss-20b로 바꿨습니다.
3. **장면 읽어 내기(파싱).** 장면 글에서 장소(Location)와 배경(Background)을 읽어 냅니다.
4. **대화 만들기.** 장면 하나마다 인물과 상대가 주고받는 긴 대화를 만들었습니다.
5. **대화 정제.** 대화를 학습 형식으로 바꾸기 전에 이상한 턴을 걸러 냈습니다(아래 "결과").
6. **학습과 점검.** 정제한 자료로 미세조정한 뒤, 모델에게 질문을 던지고 LLM 자동 평가로 채점했습니다.
7. **사실 보강.** 모델이 사실을 지어내는 문제가 나와 문서 검색(RAG)과 인물 관계 그래프 검색(RoleRAG)을 붙였습니다.

## 실제 예시

장면 하나와 그 장면에서 만든 대화의 첫 부분입니다(발표자료에 실은 실제 생성 자료).

```
[장면]
Location: 음악 대학 연습동
Background: 학생이 "하루 연습량이 얼마나 되어야 할까요?"라고 묻는 장면

[대화]
조수미(speaking): 윤아 씨, 오늘도 연습 준비 잘 됐어요?
윤아(speaking): 네, 조수미 선생님. 그런데 하루에 얼마나 시간을 투자해야 하는지 궁금해서요.
```

정제 전 자료에서 걸러 낸 턴의 예입니다. 대사가 들어가야 할 자리에 생성 모델의 계획 글이 들어가 있습니다.

```
Let's proceed.assistantfinal배경      ← 인물 이름 칸에 계획 글이 들어감
"Dialogue ... So we just alternate lines? ... Ok let's craft."   ← 대사 칸에 영어 계획 글
```

## 결과

### 1. 지나친 필터가 정상 장면을 버리고 있었다

표 읽는 법: 같은 생성 결과 1,458개를 두 방식으로 읽었을 때 몇 개를 장면으로 읽어 냈는지입니다(규칙 측정).

| 읽는 방식 | 읽어 낸 장면 | 성공률 |
|---|---|---|
| 길이 검사와 틀 문구 검사를 넣은 필터 | 264 / 1,458 | 18.11% |
| 필터를 빼고 빈 글만 제외 | 1,457 / 1,458 | 99.93% |

글자 수가 짧다는 이유로, 또 장면 틀의 문구가 남아 있다는 이유로 정상 장면까지 버리고 있었습니다. 필터를 빼고 칸을 읽을 때만 검사하도록 바꾸자 거의 전부를 읽어 냈습니다.

### 2. 생성 모델의 속생각 글이 대화에 섞였다

대화 생성에 생각하는 모델(Qwen3-30B-A3B-Thinking)을 쓰자, 모델이 답 전에 쓰는 영어 계획 글이 대화 형식과 비슷하게 나와 대사로 읽혔습니다.

표 읽는 법: 정제 전(01-25)과 정제 후(01-26) 조수미 대화 1,540개를 같은 기준으로 센 값입니다(규칙 측정).

| 시점 | 문제가 있는 대화 | 정상 턴 비율 |
|---|---|---|
| 정제 전 | 1,209 / 1,540 (78.5%) | 계산하지 않음(학습 비권장 판정) |
| 정제 후 | 776 / 1,540 (50.4%, 대부분 일부 턴만 문제) | 97.07% (정상 턴 74,847개) |

정제 후 "문제 턴이 20% 이상인 심각한 대화"는 7개(0.5%)였습니다. 이후 대화 생성에는 생각하는 모델을 쓰지 않기로 했습니다.

### 3. 프로필 사실이 대화에 거의 나오지 않았다

표 읽는 법: 정제한 조수미 대화 1,540개 가운데 프로필의 핵심 사실(본명, 출생 연도, 출생지 등)이 한 번이라도 나온 대화의 수입니다(규칙 측정).

| 항목 | 값 |
|---|---|
| 프로필 핵심 사실이 들어간 대화 | 67 / 1,540 (4.4%) |
| 출생 연도가 나온 대화 | 1개 |

대화는 대부분 조언이나 감정 이야기였고, 사실은 거의 반복되지 않았습니다. 그 결과 학습한 모델이 **출생 연도를 매번 다르게 지어냈습니다.** 그래서 두 가지를 더했습니다.

- **문서 검색(RAG):** 질문과 가까운 프로필 문단 3개를 문장 벡터 유사도로 찾아 답 앞에 붙입니다.
- **인물 관계 그래프 검색(RoleRAG):** 인물, 작품, 사건 이름(처음 60개, 나중에 이름 추출 모델로 411개)을 사전으로 두고, 질문에 나온 이름과 연결된 문단에 점수를 더 줍니다(이름 일치 +0.3, 연결 문단 +0.15). 별명과 본명처럼 같은 사람을 가리키는 이름도 하나로 묶습니다.
- 상대가 틀린 사실을 말하면 인물이 바로잡는 대화(할루시네이션 대응 대화)도 따로 만들었습니다.

### 4. 채점 도구 자체가 자주 고장 났다

모델의 답을 LLM 자동 평가로 1~7점 채점하는 단계에서도 문제가 많았습니다.

| 문제 | 규모 | 고친 방법 |
|---|---|---|
| 평가 모델의 답이 중간에 끊겨 점수를 못 읽음 | 한 번에 100개 중 67개 | 출력 길이 상한을 늘리고, 끊긴 답을 감지해 다시 요청 |
| 멀티턴 인터뷰에서 모델의 답이 끊김 | 332턴 중 310턴(93.4%) | 생성 길이 상한을 단계적으로 늘림(256 → 최대 4,096토큰) |
| 평가 모델의 안전 필터 때문에 채점 거부 | 일부 | 필터 설정 조정 |

## 그래서 무슨 뜻인가

- 프로필에서 대화를 자동으로 만드는 방식은 많은 양을 빠르게 얻을 수 있지만, **만든 자료를 그대로 믿으면 안 됩니다.** 생성 모델의 계획 글, 이름 표기 흔들림(같은 인물을 여러 이름으로 부름), 영어 턴 같은 오염을 규칙으로 하나씩 걸러야 했습니다.
- 검사는 엄격할수록 좋은 것이 아니었습니다. 지나친 필터는 정상 자료를 80% 넘게 버렸습니다. 검사는 "무엇을 버렸는지" 함께 세어 봐야 합니다.
- 말투와 분위기는 대화 자료로 잘 배우지만, **사실은 자료에 여러 번 나와야 배웁니다.** 사실이 드문 자료로 학습한 모델에는 문서 검색이 꼭 필요했습니다.

## 한계와 남은 일

- 이 시기의 채점은 끊김과 거부가 많아 완성되지 않은 상태였습니다. 이 시기 점수는 결론에 쓰지 않았습니다.
- 대화는 모두 생성 모델이 만든 것이라, 실제 사람의 대화와는 거리가 있습니다. 이 문제는 뒤에 "사람다움" 측정과 사실 보강으로 이어집니다([사료로 프로필을 다시 쓴 기록](2026-11-03-persona-profile-facts.html)).
- 이 글의 대화 자료는 첫 판입니다. 이후 인물마다 안전, 방어, 약점 보강 대화를 더해 5천 행이 넘는 판으로 커졌습니다.
