## 지금 상태

**새 방법이나 새 발견을 확정한 것은 없습니다.** Wait·Alternatively 금지는 NoWait와 같은 방법입니다. 표지별 차이(H01)는 관찰입니다. 아래는 어디가 이미 있고 어디가 비어 있는지 정리한 표입니다.

## 새로 확인한 논문

| 논문 | 내용 | 이 연구에 미치는 영향 |
|---|---|---|
| [Beyond the Opening](https://arxiv.org/abs/2610.34350) (2026-10) | R1-Distill 모델에서 첫 토큰을 바꾸면 뒤 199토큰을 고정해도 남은 길이가 달라짐. 추론 단계 개입만 함 | 첫 토큰이 길이를 좌우한다는 관찰은 이제 단독 기여가 될 수 없음. 학습 라벨 제외(A2)와 매개 분석은 없음 |
| [DoubtLess](https://arxiv.org/abs/2610.18862) (2026-10) | 작은 모델과의 대비 디코딩으로 사고 토큰 31% 감소, 정확도 유지. 금지어 묶음은 어려운 벤치에서 정확도 하락을 보고 | G1 효율 결과에 대한 반대 근거. 표지별 비교는 없음 |
| [Learning When to Think](https://arxiv.org/abs/2608.20256) (2026-08) | 강화학습으로 첫 토큰을 NoThink, Short, Long 라우팅으로 학습 | 첫 토큰을 학습하는 쪽. 라벨을 빼는 A2와 반대 방향 |
| [Revisiting Reflection Markers](https://arxiv.org/abs/2605.28305) (2026-05) | 표지 35종 억제 뒤에도 반성 응답이 거의 유지 | 표지와 행동이 다르다는 결론은 이미 있음. 표지 단어별 비교와 대체 표현 목록은 없음 |
| [Segment-Level Attribution](https://arxiv.org/abs/2602.00425) (2026-02) | 전환어로 구간을 나누고 중요 구간만 학습 | 라벨 제외 후보의 겹침을 낮음에서 중간으로 올림. 표지 토큰만 빼는 팔은 없음 |
| [SHAD·RFT](https://arxiv.org/abs/2412.14780) | 에이전트 과제에서 전환 문구를 포함한 보일러플레이트와 추론 토큰을 나눠 가중 | 전환 문구를 다르게 다룬 가장 가까운 사례. 장문 추론, 라벨 제외 없음 |
| [Structured Reasoning](https://arxiv.org/abs/2601.07180) (2026-01) | 틀린 초안을 손실에서 빼고 비평·수정만 학습 | 자기 오류 승급 후보와 부분 겹침. 오류 위치가 아니라 전체 답 판단 |
| [Base Models Know How](https://arxiv.org/abs/2510.07364) (2025-10) | 모델이 "언제" 추론 기제를 쓸지 배운다고 분석 | when을 빼고 학습하는 실험은 없음. 혼합안의 이론적 근거로 활용 |

## 후보별 판단

| 후보 | 가장 가까운 선행 | 겹침 | 결정 |
|---|---|---|---|
| 첫 토큰 모드 스위치 관찰 | Beyond the Opening, Learning When to Think | 높음 | 단독 기여로 쓰지 않음 |
| Wait·Alternatively 전역 금지 | NoWait, Revisiting Reflection Markers | 높음 | 비교 기준 |
| 표지 하나씩 제거 비교 | 묶음 금지뿐 | 낮음 | **진단 우선** |
| 표지 강제 삽입 비교 | Wait 덧붙이기(s1) | 낮음~중간 | 진단 |
| 표지 치환(Wait를 검산 문구로) | 찾지 못함 | 낮음 | 탐색 |
| 전환 표지 라벨 제외 학습 | Segment-Level Attribution, SHAD·RFT | 중간 | **1순위 학습 후보** |
| 혼합: 첫 토큰 라벨 제외 + 연쇄 표지만 라벨 제외 | 찾지 못함 | 낮음 | **혼합안** |
| 자기 오류 승급 | Structured Reasoning, RECAP 등 | 중간~높음 | 오류 위치, 자기 출력만 남음 |
| 구간별 생성 중 개입 | CGRS, ASAG, LYNX, ES-CoT | 높음 | 진단용 |
| 시작어 재라벨 | DART, Thinkless 등 | 높음 | 비교 기준 |

"찾지 못함"은 검색과 원문 확인 범위에서 못 찾았다는 뜻이며 없다는 보장이 아닙니다. Self-Affirmation 억제 논문(2506.12353)은 원문을 받지 못해 초록 수준으로만 확인했습니다.

## 혼합안

**언제 표지를 낼지는 학습하지 않고, 표지 다음의 내용만 학습합니다.** 첫 토큰 라벨을 뺀 A2를 풀이 안쪽의 전환 표지로 넓힙니다. "언제 깊이 생각할지"는 학습된 습관이 아니라 문맥과 Base 모델의 판단에 맡기고, "깊이 생각할 때 무엇을 할지"는 그대로 배우게 합니다. 이 형태는 "모델은 언제를 배운다"는 주장을 학습 조작으로 직접 시험하는 실험이 됩니다.

- **표지 전부 제외** 대 **연쇄 표지만 제외** 대 **같은 수의 무작위 토큰 제외(대조)**를 비교합니다.
- LIMO 자료에서 전환 표지는 전체 라벨의 0.53%이고, 그중 53%가 연쇄 표지입니다.
- 위험: 긴 추론 능력이 약해져 어려운 문항에서 틀릴 수 있습니다. 그 결과 자체도 "when 없이 how가 남는가"에 대한 답이 됩니다.

학습 전에 실제 라벨 위치를 다시 확인하고 대조 조건을 고정합니다.
