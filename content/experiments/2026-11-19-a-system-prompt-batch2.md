## 메인 표: Base, SFT, A1, A2, QFFT와 추론 입력을 바꾼 조건

<!-- qfft-main-table-start -->

**표 읽는 법.** 한 줄이 "모델 + 추론 입력" 하나입니다. ACC는 정답률(%), Tokens는 답 하나의 평균 출력 tokens입니다. "구분"이 줄의 뜻입니다. 기준은 학습 방법이 다른 모델들을 표준 평가 그대로 잰 값이고, 굵게 적은 A2와 QFFT가 견줄 상대입니다. 방법은 표준 SFT를 다시 학습하지 않고 추론 입력만 바꾼 값입니다. 참고는 같은 입력 변경을 다른 모델에 얹어 본 값입니다. "대기"는 지금 돌고 있는 칸입니다.

| 구분 | 모델 | 추론 입력 | GSM8K ACC | GSM8K Tokens | MATH500 ACC | MATH500 Tokens | AIME25 ACC | AIME25 Tokens |
|---|---|---|---|---|---|---|---|---|
| 기준 | Base | 기본 프롬프트 | 92.0 | 301 | 76.1 | 635 | 8.8 | 1,060 |
| 기준 | SFT | 기본 프롬프트 | 91.6 | 2,060 | 81.0 | 6,576 | 16.7 | 20,574 |
| 기준 | A1 | 기본 프롬프트 | 91.4 | 1,856 | 80.9 | 6,149 | 17.5 | 18,965 |
| 기준 | **A2** | 기본 프롬프트 | **91.6** | **888** | **81.3** | **4,587** | **17.5** | **17,735** |
| 기준 | **QFFT** | 기본 프롬프트 | **92.0** | **831** | **81.4** | **4,630** | **15.4** | **18,133** |
| 방법 (SysDrop) | SFT | 시스템 프롬프트 제거 | 91.0 | 1,517 | 80.9 | 4,899 | 19.2 | 18,382 |
| 방법 (CueDrop) | SFT | 문제 글만 | 대기 | 대기 | 81.4 | 4,221 | 대기 | 대기 |
| 참고 | A1 | 시스템 프롬프트 제거 | 91.5 | 587 | 81.6 | 3,778 | 12.5 | 16,270 |
| 참고 | A2 | 시스템 프롬프트 제거 | 91.6 | 514 | 82.0 | 3,948 | 값 없음 | 값 없음 |
| 참고 | QFFT | 시스템 프롬프트 제거 | 91.3 | 630 | 82.5 | 4,122 | 값 없음 | 값 없음 |
| 참고 | QFFT | 문제 글만 | 대기 | 대기 | 77.5 | 5,046 | 대기 | 대기 |

- **모델.** Base는 파인튜닝 전의 Qwen2.5-7B-Instruct입니다. 나머지는 모두 LIMO 817문항으로 학습했습니다. SFT는 QFFT 논문이 비교 기준으로 쓴 표준 SFT로, 시스템 프롬프트와 질문, 긴 풀이를 그대로 학습한 모델입니다. A1은 질문을 지우고, A2는 질문을 지우고 응답 첫 토큰의 loss까지 빼고, QFFT는 논문 방법대로 질문 없이 풀이만으로 학습한 모델입니다.
- **무엇을 견주는가.** A2와 QFFT는 학습 방법을 바꿔 새로 학습한 모델입니다. 방법 줄은 표준 SFT의 가중치를 그대로 두고 추론 입력만 바꾼 것입니다. A2나 QFFT 위에 얹은 것이 아니라, A2, QFFT와 나란히 견주는 다른 길입니다. 같은 입력 변경을 A1, A2, QFFT에 얹어 본 값은 참고 줄에 따로 두었습니다.
- **추론 입력.** 기본 프롬프트는 대화 틀, 시스템 프롬프트 "Please reason step by step, and put your final answer within \boxed{}.", 질문으로 이루어집니다. 시스템 프롬프트 제거는 거기서 시스템 프롬프트만 뺀 입력이고, 문제 글만은 대화 틀까지 빼고 질문 글자만 준 입력입니다. 실제 문자열은 아래 "실제 입력과 실제 답"에 있습니다.
- **크기.** GSM8K 1,319문항, MATH500 500문항, AIME25 30문항입니다. 기본 프롬프트 줄은 문항마다 16회, 나머지 줄은 4회 풀게 했습니다. 최대 32,000 tokens입니다.
- **채점.** GSM8K와 MATH500의 ACC는 `\boxed{}` 없이 끝난 답을 직접 읽어 반영하고, 표기만 다른 같은 답을 맞게 고친 값입니다(GSM8K는 평가 자료의 정답 16문항도 바로잡았습니다). AIME25는 공식 채점 스크립트 값 그대로입니다.
- **읽기.** MATH500에서 표준 SFT에 문제 글만 준 줄(CueDrop)은 ACC 81.4%, 4,221 tokens입니다. A2(81.3%, 4,587)와 QFFT(81.4%, 4,630)와 정답률이 같고 8–9% 짧습니다. GSM8K와 AIME25의 같은 칸은 아직 돌지 않았습니다. 참고 줄을 보면 A2와 QFFT도 시스템 프롬프트를 빼면 더 짧아집니다(3,948, 4,122 tokens).

11월 18일 글에서 이어지는 실험 세 묶음입니다.

1. **학습 방식별 간결 문장.** 기본 시스템 프롬프트의 "reason step by step"을 "answer concisely"로 바꾸면, SFT는 쉬운 문제는 짧게, 어려운 문제는 길게 풀었습니다. 이번에는 같은 문장을 질문 제거 SFT(A1)와 QFFT에 넣었습니다. 두 모델 모두 같은 모습이었고(MATH500 Level 1 0.41, 0.47배, AIME25 0.88, 0.93배), MATH500과 AIME25 정답률은 유지됐습니다. 시스템 프롬프트 없이 학습한 SFT는 덜 반응했습니다(MATH500 0.79배).
2. **글자와 뜻.** 학습 문장의 낱말 순서를 섞거나, 부정문으로 바꾸거나, 한국어로 번역해도 SFT는 기본처럼 길게 풀었습니다. 낱말 묶음으로도, 뜻으로도 긴 풀이가 켜지고, "하지 말라"는 부정으로는 꺼지지 않습니다.
3. **시작 상태 확장.** 시스템 프롬프트의 효과를 담은 방향을 응답 시작 위치에만 더하는 실험을 넓혔습니다. 7층에서는 효과가 없었고, 14층과 21층에서는 작동했습니다. 무관한 문장에서 뽑은 방향과 SFT 전 Instruct 모델에서는 켜지지 않았습니다. 긴 풀이 모드는 SFT 학습이 만든 것입니다.

## 왜 궁금했나

11월 18일 결과에서 세 가지가 남았습니다.

- 간결 문장의 난도 배분은 SFT만의 현상인가, 학습 방식과 상관없이 나오는가?
- SFT는 시스템 프롬프트의 글자에 반응하는가, 뜻에 반응하는가? 11월 15일에는 같은 뜻의 다른 문장(0.81배)과 무관한 문장(0.52배)만 봤습니다.
- 응답 시작 위치의 방향은 어느 층에서 작동하는가? 그 방향은 지시의 뜻에서 오는가, 시스템 프롬프트 칸이 채워졌다는 사실에서 오는가? SFT 전 모델에도 같은 기능이 있는가?

이전에 돌린 조건은 다시 돌리지 않고 저장된 결과를 기준으로 썼습니다. 판정 기준은 결과를 보기 전에 연구 기록에 적었습니다.

MATH500 Level 1 문항입니다(11월 18일 글과 같은 문항).

> What is the difference between the positive square root of 64 and the cube root of 64? (정답 4)

조건마다 첫 번째 답입니다.

| 모델과 시스템 프롬프트 | 응답의 첫머리 | 길이 (tokens) | 끝 |
|---|---|---|---|
| SFT, 기본 문장 | "Okay, so I need to find the difference between the positive square root of 64 and the cube root of 64. Let me break this down step by step." | 1,528 | `\boxed{4}` |
| SFT, 낱말 섞기 "answer step step, \boxed{}. final your put Please reason and by within" | 위와 같은 첫 문장 | 1,217 | `\boxed{4}` |
| SFT, 부정문 "Do not reason step by step, and put your final answer within \boxed{}." | "Okay, so the problem is asking for the difference …" | 983 | `\boxed{4}` |
| SFT, 한국어 "단계별로 추론하고, 최종 답을 \boxed{} 안에 넣으세요." | "Okay, so the problem is asking for the difference …" | 794 | `\boxed{4}` |
| A1, 간결 문장 | "First, find the positive square root of 64. Since 8 squared is 64 (8 × 8 = 64), the positive square root is 8." | 136 | `\boxed{4}` |
| QFFT, 간결 문장 | "First, find the positive square root of 64. Since \(8^2 = 64\), the positive square root is 8." | 93 | "8 - 4 = 4. Therefore, the answer is 4." 뒤 `boxed{4}`(역슬래시가 빠졌지만 자동 채점은 정답) |
| 시스템 프롬프트 없이 학습한 SFT, 간결 문장 | "First, find the positive square root of 64. The square root of 64 is a number that, when multiplied by itself, equals 64." | 139 | `\boxed{4}` |
| SFT 전 Instruct + SFT의 방향 (시작 위치에만) | "To find the difference between the positive square root of 64 and the cube root of 64, we'll first calculate each root separately" | 312 | `\boxed{4}` |

- 학습 문장의 낱말을 섞거나 부정하거나 번역해도 SFT는 "Okay"로 시작해 길게 풀었습니다.
- 간결 문장에서는 세 모델 모두 "First, find …"로 바로 계산했습니다.
- SFT 전 Instruct 모델은 SFT의 방향을 더해도 평소처럼 "To …"로 시작해 짧게 풀었습니다.

(이 문항에서 기본 문장 답 16개의 길이는 A1 513–1,809, QFFT 258–466 tokens입니다.)

### 중국어로 지시하면

"请逐步推理，并将最终答案放在 \boxed{} 中。"(우리말로 "단계별로 추론하고, 최종 답을 \boxed{} 안에 넣으세요")를 넣었을 때 SFT의 답은 두 갈래였습니다.

- 영어로 쓴 답 126개: "Okay, so I need to …"로 시작하고 Long-CoT 89.7%, 토큰 비 0.84배였습니다. 기본 문장과 거의 같습니다.
- 중국어로 쓴 답 74개: 모두 "好的，我需要计算 …"(우리말로 "좋아, 계산해야 할 것은 …")로 시작했습니다. "Okay"에 해당하는 말입니다. 다만 Long-CoT 판별 규칙이 영어 낱말로만 판별해서, 이 답들의 긴 풀이는 재지 못했습니다.
- 아래 결과 표의 중국어 줄에서 Okay/Alright 시작과 Long-CoT가 둘 다 62.5%인 것은 우연히 같은 값입니다. Okay/Alright 시작은 영어 답 125개(200개 가운데)이고, Long-CoT는 영어 답 113개와 판별 규칙에 걸린 중국어 답 12개(74개의 16.2%)를 더한 125개입니다.

- 실험 도중 요청에 따라 약 2시간 멈췄다가 이어서 돌렸습니다. 끊긴 칸(한국어 번역)은 처음부터 다시 돌렸습니다.
