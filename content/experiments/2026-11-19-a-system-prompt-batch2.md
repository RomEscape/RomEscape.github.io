## 한 줄 요약

11월 18일 글에서 이어지는 실험 세 묶음입니다.

1. **학습 방식별 간결 문장.** 기본 시스템 프롬프트의 "reason step by step"을 "answer concisely"로 바꾸면, SFT는 쉬운 문제는 짧게, 어려운 문제는 길게 풀었습니다. 이번에는 같은 문장을 질문 제거 SFT(A1)와 QFFT에 넣었습니다. 두 모델 모두 같은 모습이었고(MATH500 Level 1 0.41, 0.47배, AIME25 0.88, 0.93배), MATH500과 AIME25 정답률은 유지됐습니다. 시스템 프롬프트 없이 학습한 SFT는 덜 반응했습니다(MATH500 0.79배).
2. **글자와 뜻.** 학습 문장의 낱말 순서를 섞거나, 부정문으로 바꾸거나, 한국어로 번역해도 SFT는 기본처럼 길게 풀었습니다. 낱말 묶음으로도, 뜻으로도 긴 풀이가 켜지고, "하지 말라"는 부정으로는 꺼지지 않습니다.
3. **시작 상태 확장.** 시스템 프롬프트의 효과를 담은 방향을 응답 시작 위치에만 더하는 실험을 넓혔습니다. 7층에서는 효과가 없었고, 14층과 21층에서는 작동했습니다. 무관한 문장에서 뽑은 방향과 SFT 전 Instruct 모델에서는 켜지지 않았습니다. 긴 풀이 모드는 SFT 학습이 만든 것입니다.

## 왜 궁금했나

11월 18일 결과에서 세 가지가 남았습니다.

- 간결 문장의 난도 배분은 SFT만의 현상인가, 학습 방식과 상관없이 나오는가?
- SFT는 시스템 프롬프트의 글자에 반응하는가, 뜻에 반응하는가? 11월 15일에는 같은 뜻의 다른 문장(0.81배)과 무관한 문장(0.52배)만 봤습니다.
- 응답 시작 위치의 방향은 어느 층에서 작동하는가? 그 방향은 지시의 뜻에서 오는가, 시스템 프롬프트 칸이 채워졌다는 사실에서 오는가? SFT 전 모델에도 같은 기능이 있는가?

이전에 돌린 조건은 다시 돌리지 않고 저장된 결과를 기준으로 썼습니다. 판정 기준은 결과를 보기 전에 연구 기록에 적었습니다.

## 용어 풀이

| 용어 | 뜻 | 이 실험에서의 실제 값 |
|---|---|---|
| 기본 시스템 프롬프트 | 학습과 평가에 쓴 문장 | "Please reason step by step, and put your final answer within \boxed{}." |
| 간결 문장 | 기본 문장에서 "reason step by step"만 "answer concisely"로 바꾼 문장 | "Please answer concisely, and put your final answer within \boxed{}." |
| SFT | 질문과 긴 풀이를 그대로 학습한 모델 | Qwen2.5-7B-Instruct를 LIMO 817문항으로 학습 |
| 질문 제거 SFT (A1) | 학습 때 질문 자리를 비운 모델 | 같은 데이터, 같은 설정 |
| QFFT | 질문 없이 풀이만 학습하는 논문 방법 | 같은 데이터 |
| 시스템 프롬프트 없이 학습한 SFT | SFT와 같지만 학습 입력에 시스템 프롬프트를 넣지 않은 모델 | 11월 11일에 학습 |
| 토큰 비 | 같은 문항에서 바꾼 조건의 평균 길이 ÷ 기본 문장의 평균 길이를 문항마다 구해 기하평균한 값 | 1보다 작으면 짧아진 것 |
| Level 1–5 | MATH500 문항에 붙은 난이도 | 1이 가장 쉬움 |
| Long-CoT | 재검토와 되돌아보기가 들어간 긴 풀이 | 원본 논문 분석 코드의 판별 규칙 그대로. 영어 낱말로 판별해 중국어 답은 잡지 못함 |
| Okay/Alright 시작 (%) | 응답이 "Okay"나 "Alright"로 시작하는 비율 | SFT는 기본 문장에서 100% |
| 방향 v | 시스템 프롬프트가 있을 때와 없을 때, 응답 시작 직전 위치 은닉 상태의 평균 차이 | 층마다 크기가 다름(7층 16.0, 14층 37.6, 21층 92.5) |
| 시작 위치에만 더하기 | 응답 시작 직전 위치 한 곳에만 v를 더함 | 11월 18일에 14층에서 긴 풀이 모드를 대부분 되돌림(0.82배) |
| 95% CI | 문항을 다시 뽑아 2,000번 계산했을 때 값의 95%가 들어오는 범위 | 대괄호 안의 두 수 |

## 실험 예시

### 문항 하나로 따라가 보기

MATH500 Level 1 문항입니다(11월 18일 글과 같은 문항).

> What is the difference between the positive square root of 64 and the cube root of 64? (정답 4)

조건마다 첫 번째 답입니다.

| 모델과 시스템 프롬프트 | 응답의 첫머리 | 길이 (tokens) | 끝 |
|---|---|---|---|
| SFT, 기본 문장 | "Okay, so I need to find the difference between the positive square root of 64 and the cube root of 64. Let me break this down step by step." | 1,528 | `\boxed{4}` |
| SFT, 낱말 섞기 "answer step step, \boxed{}. final your put Please reason and by within" | 위와 같은 첫 문장 | 1,217 | `\boxed{4}` |
| SFT, 부정문 "Do not reason step by step, and put your final answer within \boxed{}." | "Okay, so the problem is asking for the difference …" | 983 | `\boxed{4}` |
| SFT, 한국어 "단계별로 추론하고, 최종 답을 \boxed{} 안에 넣으세요." | "Okay, so the problem is asking for the difference …" | 794 | `\boxed{4}` |
| A1, 간결 문장 | "First, find the positive square root of 64. Since 8 squared is 64 (8 × 8 = 64), the positive square root is 8." | 136 | `\boxed{4}` |
| QFFT, 간결 문장 | "First, find the positive square root of 64. Since \(8^2 = 64\), the positive square root is 8." | 93 | "8 - 4 = 4. Therefore, the answer is 4." 뒤 `boxed{4}`(역슬래시가 빠졌지만 자동 채점은 정답) |
| 시스템 프롬프트 없이 학습한 SFT, 간결 문장 | "First, find the positive square root of 64. The square root of 64 is a number that, when multiplied by itself, equals 64." | 139 | `\boxed{4}` |
| SFT 전 Instruct + SFT의 방향 (시작 위치에만) | "To find the difference between the positive square root of 64 and the cube root of 64, we'll first calculate each root separately" | 312 | `\boxed{4}` |

- 학습 문장의 낱말을 섞거나 부정하거나 번역해도 SFT는 "Okay"로 시작해 길게 풀었습니다.
- 간결 문장에서는 세 모델 모두 "First, find …"로 바로 계산했습니다.
- SFT 전 Instruct 모델은 SFT의 방향을 더해도 평소처럼 "To …"로 시작해 짧게 풀었습니다.

(이 문항에서 기본 문장 답 16개의 길이는 A1 513–1,809, QFFT 258–466 tokens입니다.)

### 중국어로 지시하면

"请逐步推理，并将最终答案放在 \boxed{} 中。"(우리말로 "단계별로 추론하고, 최종 답을 \boxed{} 안에 넣으세요")를 넣었을 때 SFT의 답은 두 갈래였습니다.

- 영어로 쓴 답 126개: "Okay, so I need to …"로 시작하고 Long-CoT 89.7%, 토큰 비 0.84배였습니다. 기본 문장과 거의 같습니다.
- 중국어로 쓴 답 74개: 모두 "好的，我需要计算 …"(우리말로 "좋아, 계산해야 할 것은 …")로 시작했습니다. "Okay"에 해당하는 말입니다. 다만 Long-CoT 판별 규칙이 영어 낱말로만 판별해서, 이 답들의 긴 풀이는 재지 못했습니다.

### 1. 학습 방식별 간결 문장

| 모델 | GSM8K | MATH500 | AIME25 |
|---|---|---|---|

**표 읽는 법.** A1 행의 MATH500 Level 1 → 5 "0.41 … 0.57"은 가장 쉬운 문제에서 기본 문장 길이의 41%만 쓰고, 가장 어려운 문제에서는 57%를 썼다는 뜻입니다. AIME25 0.88은 더 어려운 경시 문제에서는 88%를 썼다는 뜻입니다. 쉬울수록 더 많이 줄었습니다.

- 간결 문장의 난도 배분은 SFT, A1, QFFT 모두에서 나왔습니다. MATH500과 AIME25에서 정답률이 떨어졌다고 말할 수 있는 모델은 없었습니다.
- 시스템 프롬프트를 아예 빼는 것과 비교하면 이렇습니다.
  - A1은 시스템 프롬프트를 빼면 AIME25 정답률이 5%p 떨어졌지만, 간결 문장에서는 기본과 같았습니다(17.5%).
  - QFFT는 시스템 프롬프트를 빼면 GSM8K 답의 37%에서 `\boxed{}`를 빼먹었지만(정답률 −30.9%p), 간결 문장에서는 95% 지켰습니다.
- 쉬운 GSM8K에서는 A1의 정답률이 3.0%p 낮았습니다.
- 시스템 프롬프트 없이 학습한 SFT는 덜 줄었습니다. 학습 때 시스템 프롬프트를 봐야 그 칸의 문장에 길이가 크게 의존한다는 11월 12일 결과와 같은 방향입니다.
- 엔진 대조: 같은 엔진으로 다시 만든 SFT 기본 문장의 GSM8K 정답률은 저장 결과와 0.2%p 차이였습니다. 같은 엔진 기준으로 보면 간결 문장의 GSM8K 정답률 차는 −1.7 [−3.5, +0.2]%p였습니다.

**표 읽는 법.** "켜짐"은 토큰 비가 0.85 이상이고 Long-CoT가 기본의 90% 이상인 경우, "꺼짐"은 토큰 비가 0.70 이하인 경우입니다(미리 정한 기준).

- 미리 정한 해석 규칙은 "글자에 의존"이라고 판정했습니다. 그러나 이 판정은 중국어 칸이 "켜짐"에 못 미친 데서 나왔고, 그 원인은 판별 규칙이 중국어 답의 긴 풀이를 잡지 못한 것입니다. 중국어 문장에 영어로 답한 경우만 보면 0.84배, Long-CoT 89.7%로 켜져 있었습니다.
- 그래서 이렇게 읽습니다. 학습 문장의 낱말이 다 있으면 순서가 엉망이어도 켜지고, 겹치는 낱말이 없는 번역으로도 켜지며, "Do not"으로 부정해도 꺼지지 않습니다. 무관한 문장으로는 켜지지 않습니다.

- 긴 풀이를 켜는 정보는 7층에는 없고, 가운데 층(14층)부터 뒤쪽 층(21층)에 있습니다.
- 무관한 문장에서 뽑은 방향은 켜지 않았습니다. 이 방향은 크기가 기본 문장 방향의 31%이고, 둘의 방향 유사도(cos)는 0.17입니다. 크기를 맞춘 비교는 하지 않았습니다.
- SFT에서 뽑은 방향을 SFT 전 Instruct 모델에 넣으면 아무것도 바뀌지 않았습니다(200개 중 189개가 "To"로 시작). 이 긴 풀이 모드는 원래 모델 안에 있던 것을 꺼내는 것이 아니라, SFT 학습이 만든 것입니다.
- 어려운 AIME25에서는 시작어만 Okay로 바뀌고 길이와 정답률은 그대로였습니다. 원래도 길게 풀기 때문입니다.

## 이 결과로 말할 수 있는 것과 없는 것

**말할 수 있는 것**

- 학습 없이 시스템 프롬프트 한 문장만 바꿔도(간결 문장), 서로 다른 세 학습 방식(SFT, A1, QFFT)에서 모두 쉬운 문제는 짧게, 어려운 문제는 길게 배분됩니다.
- SFT의 긴 풀이는 학습 문장의 낱말 묶음으로도, 같은 뜻의 번역으로도 켜지며, "Do not"으로 부정해도 꺼지지 않습니다.
- 시작 위치에서 긴 풀이를 켜는 정보는 가운데 층부터 생기고, 지시의 뜻에서 오며, SFT 학습이 만든 것입니다.

**아직 말할 수 없는 것**

- 간결 문장이 어려운 문제의 정답률을 지킨다(AIME25 30문항이라 범위가 ±5–10%p).
- 쉬운 GSM8K에서 간결 문장이 정답률을 낮춘다(A1 −3.0%p, SFT는 같은 엔진 기준 구간에 0 포함).
- 무관한 문장 방향이 크기를 맞춰도 켜지지 않는다(크기를 맞춘 비교 안 함).
- 중국어로 쓴 답이 긴 풀이인지(판별 규칙의 언어 한계).
