## 한 줄 요약

위험한 요청에 대한 인물 모델의 반응을 재는 시험지와 채점 방식을 직접 설계했습니다. **11월 3일 기준 위반 응답률은 김홍도 모델 9.0%, 정선 모델 21.4%, 조수미 모델 20.6%**로, 학습 전 기반 모델(28.8~38.8%)보다 모두 낮았습니다. 1차 목표(위반 20% 이하)는 김홍도 모델만 넘었습니다. 11월 5일 새로 학습한 김홍도 7.8B 모델은 위반 응답률이 21.5%로 올라, 원인을 찾기 전에는 외부 공개를 하지 않기로 했습니다. 모든 점수는 LLM 자동 평가이며 사람 점수가 아닙니다.

## 왜 필요했나

- 인물 대화 모델은 실존했거나 실존하는 인물의 말투로 답합니다. 사용자가 위험한 요청을 하거나 힘든 마음을 털어놓을 때, 인물다움을 지키면서도 안전하게 답해야 합니다.
- 인물 대화 평가에서 흔히 쓰는 Neeko 방식은 1~7점으로 인물다움을 재지만 안전성은 재지 않습니다. 공개 안전성 평가들도 1~7점이 아니라 **위반 비율**로 보고합니다.
- 국내에 공인된 합격선도 찾지 못했습니다. 국내 표준 문서에 "유해성 벤치마크 차단율 95% 이상"이라는 **예시**가 있을 뿐 의무 기준은 아닙니다.
- 그래서 공개 벤치마크의 분류와 지표를 참고해 시험지, 채점 기준, 목표값을 직접 정했습니다. 목표값은 공인 기준이 아니라 **자체로 정한 제안값**입니다.

## 용어 풀이

| 용어 | 뜻 | 이 글에서의 실제 값 |
|---|---|---|
| 위반 응답률 | 위험한 요청에 실제로 해로운 답을 낸 비율. 위반 답 ÷ 유효 답 | 김홍도 모델 9.0% (25/277) |
| 과잉 거절률 | 위험하지 않은 정당한 질문을 위험하다며 거절한 비율 | 정선 모델 10.0% (4/40) |
| 안전 점수 | 100 − 위반 응답률 | 김홍도 모델 91.0 |
| 기반 모델 대비 배수 | 우리 모델의 위반 응답률 ÷ 학습 전 기반 모델의 위반 응답률. 1보다 작으면 학습으로 더 안전해졌다는 뜻 | 0.26 |
| 기반 모델 | 학습 전의 원래 모델. 여기서는 EXAONE 3.5 | 김홍도 경로 35.2% |
| 유효 답 | 평가 모델이 판정을 제대로 돌려준 답. 판정 실패(무효)는 분모에서 뺌 | 280문항 중 261~277 |
| 평가 모델 | 답을 읽고 위반인지 판정하는 다른 대형 언어 모델 | gpt-6-luna |
| 통제 답 | 정답(위반인지 아닌지)을 미리 아는 답. 평가 모델이 제대로 판정하는지 시험하는 데 씀 | 51개 |
| 싱글턴, 멀티턴 | 한 번 묻고 끝나는 질문, 여러 차례 이어지는 대화 | 인물당 싱글턴 320문항, 멀티턴 35대화 |

## 무엇을 했나

1. **공개 자료 조사.** AILuminate(유형 분류, 위반 응답률), HarmBench(공격 성공률, 판정 모델과 사람 라벨의 일치 93.19%), StrongREJECT(0~1점 채점), XSTest(과잉 거절 확인)를 원문으로 확인했습니다.
2. **시험지 설계.** 위험 7유형과 과잉 거절 확인용 대조 질문으로 나눴습니다. 유형마다 싱글턴 40문항, 인물당 싱글턴 320문항과 멀티턴 35대화, 영어 62문항, 그 밖의 외국어 20문항입니다. 시험 문항은 학습 자료와 글자가 겹치지 않게 확인했습니다(3글자 조각 겹침 0.6 이상 0건).
3. **지표 결정.** 주 지표는 유형 1~7 핵심 280문항의 위반 응답률, 보조 지표는 대조 40문항의 과잉 거절률입니다.
4. **평가 모델 검증.** 정답을 아는 통제 답 51개로 평가 모델 두 개를 비교한 뒤 하나를 골랐습니다(아래 표). 위반으로 판정된 답 일부는 다른 LLM 으로 다시 확인했습니다.
5. **목표 결정(결과를 열기 전에).** 1차 위반 20% 이하(안전 점수 80), 과잉 거절 10% 이하, 기반 모델 대비 1.5배 미만. 이후 단계 목표는 안전 점수 90, 최종 95입니다.
6. **학습 자료 보강.** 유형별 안전 학습 행을 만들고, 위기(힘든 마음을 털어놓는 대화) 응답은 위험 단계별로 다시 썼습니다(아래 "실제 예시").
7. **측정.** 11월 3일에 그때의 최고 모델과 기반 모델을 같은 시험지로 쟀고, 11월 5일 새 7.8B 모델을 다시 쟀습니다.

## 평가 모델 고르기

표 읽는 법: 정답을 아는 통제 답 51개를 두 평가 모델에 채점시킨 결과입니다. 나쁜 답은 잡을수록, 좋은 답 오판과 무효는 적을수록 좋습니다. 미리 정한 기준은 민감도 90% 이상, 오판 10% 이하, 무효 5% 이하였습니다.

| 항목 | gpt-6-luna | gpt-4.1-mini |
|---|---|---|
| 나쁜 답을 잡음(최종 판정 기준) | 100% (23/23) | 50% (2/4) |
| 민감도(채점표 규칙 그대로) | 73.9% (17/23) | 25.0% (1/4) |
| 좋은 답을 위반으로 오판 | 0/27 | 판정 0건 |
| 무효와 미회수 | 2.6% | 93.6% |
| 같은 답 다시 채점 | 97.2% 일치, κ 0.953 | 유효 쌍 없음 |

- gpt-4.1-mini 는 판정의 93.6%가 무효라 쓸 수 없었습니다.
- gpt-6-luna 도 채점표 규칙 그대로는 민감도 73.9%로 기준에 못 미쳤습니다. 놓친 6건은 모두 과잉 거절 통제였는데, 결과를 본 뒤 통제 정답표 쪽 결함(어떤 평가 모델도 맞힐 수 없는 정답)으로 확인했습니다. 그래서 gpt-6-luna 로 진행하되 두 수치를 함께 보고합니다.

## 실제 예시

위기 대응 학습 자료는 문항과 답 원문을 공개하지 않고, 바꾼 방법과 수치만 적습니다.

1. **처음 판의 문제.** 위기 대화의 답 뒷부분이 거의 모든 대화에서 같은 문장이었습니다. 김홍도 위기 답 227차례 중 가장 흔한 한 문장이 67.0%를 차지했습니다. 이대로 학습하면 모델이 상황과 관계없이 정해진 문장을 외워 말합니다.
2. **문장 다양화.** 위기 차례만 다시 쓰게 하면서, 요소마다 표현 방향을 무작위로 주고 많이 쓴 문장은 쓰지 못하게 했습니다. 사용자 말은 그대로 두었습니다.
3. **결과.** 가장 흔한 문장 비율이 김홍도 67.0% → 6.6%, 정선 61.5% → 7.7%로 줄었고, 한 대화 안에서 같은 문장을 반복하는 대화는 김홍도 25/67 → 0/67, 정선 34/72 → 0/74가 됐습니다.
4. **위험 단계별 재작성.** 그다음에는 위험이 낮으면 가볍게(공감, 부드러운 확인, 도움 권유), 위험이 높을 때만 전체 대응 절차를 밟도록 단계마다 다르게 다시 만들었습니다. 다시 만든 대화는 LLM 으로 모두 검토하고 통과한 대화만 학습에 넣었습니다.

## 결과

표 읽는 법: 11월 3일 당시 인물별 최고 모델의 값입니다(김홍도, 정선은 새로 학습한 2.4B 모델, 조수미는 7.8B 모델). 위반 응답률과 과잉 거절률은 낮을수록 좋고, 마지막 줄은 학습 전 기반 모델과 비교한 배수입니다. 모두 gpt-6-luna 자동 평가이며 사람 점수가 아닙니다.

|---|---|---|---|---|
| 위반 응답률 | 1차 20% 이하 | **9.0%** (25/277) | 21.4% (59/276) | 20.6% (56/272) |
| 안전 점수(100 − 위반률) | 1차 80 | 91.0 | 78.6 | 79.4 |

| 기반 모델 위반 응답률 | 참고 | 35.2% (92/261) | 38.8% (107/276) | 28.8% (79/274) |
| 기반 모델 대비 배수 | 1.5배 미만 | **0.26** | **0.55** | **0.71** |

**11월 5일 새 7.8B 모델.** 프롬프트 생성기와 함께 전달한 김홍도, 정선 7.8B 모델을 같은 방식으로 다시 쟀습니다. 이 측정은 정체 확인 7문항이 포함돼 분모가 조금 다릅니다.

| 지표 | 김홍도 2.4B(앞선 최고) | 김홍도 7.8B(새 판) | 정선 2.4B | 정선 7.8B(새 판) |
|---|---|---|---|---|
| 유형 1~7 위반 응답률 | 10.2% (29/284) | **21.5% (60/279)** | 21.9% (62/283) | 21.1% (60/285) |
| 멀티턴 위반 대화 | 2/34 | **17/34** | 15/35 | 14/34 |

- 김홍도 7.8B 새 판은 앞선 최고 모델보다 위반이 두 배로 늘었습니다. 기반 모델 대비 1.5배 미만 기준은 여전히 맞지만, **외부 공개 전에 해결할 항목**으로 정했습니다.
- 원인(7.8B 바탕, 새 학습 자료, 3인칭 교정 강화학습 가운데 무엇인지)은 아직 확인하지 못했습니다.

## 그래서 무슨 뜻인가

- 학습으로 세 인물 모델 모두 기반 모델보다 덜 위험해졌습니다. 같은 시험지에서 위반이 0.26~0.71배입니다.
- 그러나 1차 목표를 넘은 것은 김홍도 모델 하나입니다. 정선, 조수미 모델은 20% 경계에 있고, 조수미 모델은 과잉 거절도 17.5%로 높습니다. 조수미 7.8B 에는 준비한 안전 자료가 아직 들어가지 않았습니다.
- 모델을 바꾸면 안전성이 크게 달라질 수 있습니다. 새 모델을 낼 때마다 같은 시험지로 다시 재야 합니다.

## 한계와 남은 일

- **사람 대조가 없습니다.** 평가 모델 판정을 사람 라벨과 맞춰 본 적이 없습니다. 11월 5일 재판정의 일치도도 세 분류 기준 κ 0.40, 통과 여부 기준 κ 0.74로 높지 않습니다.
- **빠진 범주가 있습니다.** 화학, 생물, 방사능, 핵 관련 핵심 문항이 0개입니다. 유형 1의 위험 단계 라벨도 사람 확인을 거치지 않았습니다.
- **통제 답이 적습니다.** 51개이고, 채점 규칙 29개 중 3개만 대응합니다.
- **남은 일:** 김홍도 7.8B 위반 증가 원인 찾기, 조수미 7.8B 에 안전 자료 반영 여부 결정, 위험, 위기 대응 규칙을 다음 판에 넣고 다시 측정, 사람 검수.
