## 한 줄 요약

문제를 지우고 학습한 모델이 풀이 도중 문제로 되돌아가는 습관을 잃었을까 궁금해 셌습니다. **문제의 말을 그대로 다시 쓰는 빈도는 모델끼리 거의 비슷했습니다.** 처음에는 "질문 없이 학습한 모델이 더 자주 다시 쓴다"고 적었는데, 세는 방법에 수식이 섞여 있었습니다. 차이의 대부분은 문제에 나온 **수식을 풀이에서 다시 쓰는 것**이었습니다.

## 왜 궁금했나

질문 없이 학습한 모델은 학습 때 문제를 본 적이 없습니다. 그런데 학습 자료인 긴 풀이 안에는 "the problem says ..."처럼 문제로 되돌아가는 문장이 들어 있습니다. 그렇다면 시험 때 실제 문제를 다시 보는 습관이 약해졌을 수 있습니다. 약해졌다면 문제를 잘못 읽어 틀리는 일이 늘 수 있습니다.

## 용어 풀이

| 용어 | 쉬운 뜻 | 이 글에서의 예 |
|---|---|---|
| 토큰 | 글을 나눈 작은 단위. 이 분석에서는 영어 단어, 숫자, 기호 하나씩을 1개로 셉니다 | `the`, `196`, `{` |
| 긴 답 | 위 기준으로 1,000토큰 이상인 답 | SFT 6,753개, A2 3,565개 |
| 늦은 복사 | 답의 앞 128토큰을 지난 뒤, 문제에 있던 연속 6토큰이 그대로 나오는 것 | 아래 예시 |
| 자연어 복사 | 늦은 복사 중 영어 단어(4글자 이상, 수식 명령 제외)가 3개 이상 든 것 | `Find the angle between these lines` |
| 수식 복사 | 그 밖의 늦은 복사 | `\sum_{k = 1}^\infty` |
| 표지 | 풀이 도중 방향이 바뀔 때 나오는 말 | `Wait`, `Let me check` |
| SFT | 문제와 긴 풀이를 함께 보고 학습한 모델 | 비교 기준 |
| A1, A2, QFFT | 문제를 지우고 학습한 모델들 | 비교 대상 |
| S1.1 | LIMO와 다른 학습 자료. 따로 학습한 모델로 재현을 확인합니다 | 1,000개 풀이 |
| 비 | 해당 모델의 1,000토큰당 횟수 ÷ SFT의 횟수. 1보다 크면 더 많이 씀 | 1.16배 |

## 어떻게 셌나

저장된 MATH500 문제 500개, 모델당 16개 답(모델당 8,000개)을 씁니다. 새 생성은 없습니다.

1. 문제와 답에서 수식 구분 기호(`$`, `\(` 등)를 지우고 소문자로 바꿉니다.
2. 문제의 연속 6토큰 묶음을 모두 만듭니다. 4글자 이상 단어나 숫자가 2개 이상 든 묶음만 씁니다.
3. 답의 앞 128토큰을 지난 곳에서 그 묶음이 그대로 나오면 "늦은 복사"로 셉니다. 겹치는 일치는 한 번으로 합칩니다.
4. 긴 답만 씁니다. 짧은 답까지 넣으면 짧게 답하는 모드의 비율 차이가 섞입니다.
5. 두 모델 모두 긴 답이 4개 이상인 문제에서 문제별 비율을 내고, 평균의 비와 95% 구간을 문제 다시 뽑기 2,000번으로 구합니다.

**결과를 보기 전에 정한 기준.** A1, A2, QFFT 중 두 모델 이상이 같은 방향으로 SFT의 1.5배 이상(또는 1/1.5 이하)이고 95% 구간이 1을 넘지 않으면 "모델 간 차이 후보"입니다.

**자연어 복사의 실제 예.** 문항 7(난도 4)의 A2 답입니다. 문제는 두 직선 사이의 각을 묻고, 문제 끝 문장은 `Find the angle between these lines, in degrees.`입니다. 답 도중 `Wait` 뒤에 그 문장이 그대로 다시 나옵니다.

```text
Wait, but the problem says "Find the angle between these lines, in degrees." Since the angle between two lines is the angle between their direction vectors, ...
```

**수식 복사의 실제 예.** 문항 1의 문제에는 다음 식이 있습니다.

```text
\[p = \sum_{k = 1}^\infty \frac{1}{k^2} \quad \text{and} \quad q = \sum_{k = 1}^\infty \frac{1}{k^3}.\]
```

답을 쓰는 동안 이 식의 일부가 풀이 안에서 여러 번 다시 나옵니다. 처음 계산에서는 `\frac`, `infty` 같은 수식 명령이 "4글자 이상 단어"로 세어져 이런 수식도 "문제 문장을 다시 쓴 것"으로 함께 집계됐습니다. 이 문항의 한 A2 답에는 늦은 복사가 153번 있었습니다.

## 결과

칸은 "1,000토큰당 횟수"이고, 괄호 안은 SFT 대비 비 [95% 구간]입니다.

**LIMO로 학습한 모델**

| 모델 | 자연어 복사 | 수식 복사 |
|---|---|---|
| SFT | 0.416 (기준) | 2.347 (기준) |
| A1 | 0.408 (0.96배 [0.90, 1.03]) | 2.950 (1.33배 [1.20, 1.49]) |
| A2 | 0.428 (1.16배 [1.08, 1.27]) | 3.812 (1.73배 [1.52, 1.99]) |
| QFFT | 0.434 (1.05배 [0.97, 1.14]) | 3.243 (1.52배 [1.33, 1.76]) |

**S1.1로 따로 학습한 모델**

| 모델 | 자연어 복사 | 수식 복사 |
|---|---|---|
| SFT | 0.517 (기준) | 2.206 (기준) |
| A1 | 0.556 (1.04배 [0.98, 1.09]) | 3.407 (1.57배 [1.43, 1.73]) |
| A2 | 0.453 (1.21배 [1.11, 1.33]) | 4.097 (2.04배 [1.77, 2.36]) |
| QFFT | 0.365 (0.98배 [0.89, 1.06]) | 3.307 (1.86배 [1.58, 2.20]) |

자연어 복사는 대부분 구간이 1 근처입니다. A2만 1.16–1.21배로 약간 많습니다. 수식 복사는 질문 없이 학습한 모델이 1.33–2.04배로 뚜렷하게 많습니다.

**미리 정한 기준의 판정(처음 계산, 수식 포함): 후보 아님.** A2만 1.63배로 기준을 넘고 QFFT는 1.44배, A1은 1.26배였습니다. 수식을 뺀 자연어만 보면 차이는 더 작습니다.

다른 관찰:

- 문제 안에서 정답 답과 오답 답을 비교하면 "복사가 있는 답"의 비율 차이는 모델마다 −2.1 – −3.1%p이고 모두 0을 포함합니다. 문제를 다시 쓴 답이 더 잘 맞는다는 근거는 없습니다.
- 수식 복사가 더 많은 것은 긴 답의 길이 차이만으로 설명되지 않았습니다. 수식과 자연어를 나누기 전 계산에서 같은 길이 구간끼리 비교해도 A2가 SFT의 1.37–2.00배, QFFT가 1.24–1.73배였습니다.

## 정정

이 글의 내용과 함께, 앞서 올린 [전체 점검](2026-11-09-a-diagnosis.html)의 "질문 없이 학습한 모델이 문제 문장을 더 자주 다시 쓴다"는 표현을 고쳤습니다. 숫자는 "문제에 있던 연속 토큰 재사용"을 센 것이고, 그중 대부분이 수식이었습니다.

## 그래서 무슨 뜻인가

- 문제를 지우고 학습해도 **말로 문제에 되돌아가는 습관은 크게 줄지 않았습니다.** 예상했던 약화는 보이지 않습니다.
- 대신 문제의 수식을 풀이에서 더 자주 그대로 씁니다. 왜 그런지는 재지 않았습니다.
- 어느 쪽도 정답률과 연결되지 않아, 방법 후보로 올리지 않고 설명 재료로만 남깁니다.

## 다른 연구와 겹치는가

문제를 다시 읽게 하는 방법은 이미 많이 연구됐습니다([RE2](https://arxiv.org/abs/2309.06275), [Echoes as Anchors](https://arxiv.org/abs/2602.06600) 등). 그래서 일반적인 다시 읽기를 방법으로 주장하지 않습니다. 질문 없이 학습한 모델과 보통 학습 모델의 재참조 빈도를 비교한 연구는 이번 검색에서 찾지 못했습니다. 찾지 못했다는 것이 없다는 보장은 아닙니다.

## 한계

- 글자가 그대로 같은 경우만 셉니다. 바꿔 말한 재참조는 세지 못합니다.
- 자연어와 수식의 구분은 단어 수로 나눈 단순한 규칙입니다. 수식을 나누는 규칙은 결과를 본 뒤 추가했습니다.
- 복사가 "되돌아가기"인지 단순 반복인지는 문장 뜻을 읽어 판단하지 않았습니다.

## 다음에 할 일

방법 후보가 아니므로 추가 실험은 하지 않습니다. 토큰을 많이 쓰는 문제의 답이 실제로 무엇을 하고 있는지(되풀이, 후보 대입, 정답이 나온 뒤 잃기 등)는 별도의 전수 진단에서 다룹니다.
