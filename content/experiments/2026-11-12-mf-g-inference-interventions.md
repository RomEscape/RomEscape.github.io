## 한 줄 요약

latent에 기대는 정도는 넣는 layer를 따라갔습니다. L0에 넣으면 latent를 비울 때 크게 떨어지고, L7에 넣으면 덜 떨어집니다. 다만 latent를 비우면 모델이 풀이를 글로 쓰는 쪽으로 넘어가는 경우가 많아, "덜 떨어짐"의 일부는 그 덕분이었습니다.

## 왜 궁금했나

학습한 모델이 답할 때 latent 내용을 실제로 쓰는지 보려면, 학습은 그대로 두고 추론할 때만 latent를 바꿔 보면 됩니다. 처음 결과를 보고는 Middleflow가 "더 강건하다"고 읽을 수도 있었는데, 그렇게 읽어도 되는지 확인하려 했습니다.

## 용어 풀이

| 용어 | 뜻 | 종류 |
|---|---|---|
| latent 건너뜀 | latent 계산 없이 답의 position만 6칸 비움 | 내용을 비움 |
| 0 벡터 삽입 | 매 step 다음 position에 넣는 벡터를 0으로 | 내용을 비움 |
| 답할 때 가림 | latent 6개를 정상 계산하되 답 토큰이 latent 위치를 보지 못하게 함 | 내용을 비움 |
| 잡음 삽입 | 넣는 벡터를 크기가 같은 무작위 방향 벡터로(시드 11) | 틀린 내용 |
| 다른 문항의 latent | 같은 평가 묶음 안에서 한 칸씩 밀어 옆 문항의 벡터를 넣음 | 틀린 내용 |
| 계산식을 글로 씀 | 답 글에 학습 자료의 풀이 형식 `<<계산식>>`이 나옴 | 글로 쓴 풀이 |

## 방법

1. 학습을 마친 CODI(L0에 넣음), L13→L0(L0에 넣음), Middleflow(L7에 넣음)를 그대로 씁니다.
2. 추론 때 위 다섯 가지 방법으로 latent 자리만 바꿔 GSM8K를 풀게 합니다.
3. 11-24에 저장된 답 글을 다시 읽어, 계산식을 글로 쓴 답의 비율과 그 답의 정답률을 셌습니다.

[![추론 때 latent를 비우거나 틀린 내용을 넣었을 때 세 모델의 GSM8K 정확도](../uploads/middleflow/meeting-2026-11-12/inference-interventions.png)](../uploads/middleflow/meeting-2026-11-12/inference-interventions.png)

*괄호는 그대로일 때보다 몇 점 바뀌었는지입니다. 점선은 처음부터 latent 없이 학습한 모델(52.2)입니다.*

## 실험 예시

GSM8K 50번 문항: "Lloyd has an egg farm. His chickens produce 252 eggs per day and he sells them for $2 per dozen. How much does Lloyd make on eggs per week?" (정답 294)

| 모델과 조건 | 출력 | 채점 |
|---|---|---|
| CODI, 그대로 | The answer is: 294 | 맞음 |
| CODI, latent 건너뜀 | The answer is: 42 | 틀림. 하루 판매액에서 멈춤 |
| CODI, 0 벡터 | The answer is: 42 | 틀림 |
| L13→L0, 0 벡터 | 42 | 틀림 |
| Middleflow, 그대로 | The answer is: 294 | 맞음 |
| Middleflow, latent 건너뜀 | <<2*7=14>> <<252/12=21>>The answer is: 294 | 맞음. 계산식을 글로 씀 |
| Middleflow, 0 벡터 | <<2*7=14>> <<252/12=21>>The answer is: 294 | 맞음. 계산식을 글로 씀 |
| CODI, 다른 문항의 latent | The answer is: 210 | 틀림 |
| Middleflow, 다른 문항의 latent | The answer is: 630 | 틀림 |

## 결과

**정확도 변화 (GSM8K, 그대로일 때 대비 점수 차).**

| 추론 때 바꾼 것 | CODI (L0) | L13→L0 (L0) | Middleflow (L7) |
|---|---:|---:|---:|
| 그대로 | 53.4 | 53.1 | 50.4 |
| latent 건너뜀 | −17.3 | −14.6 | −4.0 |
| 0 벡터 | −26.2 | −20.6 | −2.2 |
| 답할 때 가림 | −17.2 | −14.9 | −4.3 |
| 잡음 | −18.7 | −14.2 | −6.2 |
| 다른 문항의 latent | −42.2 | −37.1 | −25.9 |

**계산식을 글로 쓴 답 (11-24 추가 확인).**

| 조건 | 글로 쓴 답 비율 | 그 답의 정답률 | 안 쓴 답의 정답률 | 전체 |
|---|---:|---:|---:|---:|
| CODI, 그대로 | 0.0% | – | 53.4 | 53.4 |
| CODI, latent 건너뜀 | 43.0% | 52.7 | 23.5 | 36.1 |
| CODI, 0 벡터 | 11.3% | 60.4 | 23.0 | 27.2 |
| L13→L0, latent 건너뜀 | 36.1% | 45.0 | 34.8 | 38.4 |
| L13→L0, 0 벡터 | 31.8% | 42.7 | 27.7 | 32.4 |
| Middleflow, 그대로 | 0.0% | – | 50.4 | 50.4 |
| Middleflow, latent 건너뜀 | 36.3% | 51.8 | 43.3 | 46.4 |
| Middleflow, 0 벡터 | 45.9% | 51.1 | 45.8 | 48.2 |
| 세 모델, 다른 문항의 latent | 0.1~2.4% | – | – | 11.2~24.5 |

**표 읽는 법.** 학습한 대로 풀 때는 세 모델 모두 계산식을 쓰지 않았습니다. latent를 비우면 일부 답이 풀이를 글로 쓰는 쪽으로 넘어가고, 그런 답은 50% 안팎을 맞혔습니다. 글로 쓰지 않은 답만 보면 CODI는 23%대로 떨어지고 Middleflow는 43~46%를 유지했습니다.

## 그래서 무슨 뜻인가

- **넣는 layer가 latent 의존도를 정합니다.** L13→L0과 Middleflow는 같은 L13에서 뽑으므로, 둘을 가른 것은 넣는 곳입니다.
- **세 모델 모두 latent 내용을 읽습니다.** 다른 문항의 latent를 넣으면 셋 다 크게 떨어집니다.
- **Middleflow가 덜 떨어진 이유는 두 가지가 섞여 있습니다.** 하나는 글로 풀이를 쓰는 쪽으로 더 자주 넘어간 것이고(0 벡터 45.9% 대 CODI 11.3%), 다른 하나는 글로 쓰지 않은 답에서도 덜 떨어진 것입니다(45.8 대 23.0). 그래서 "강건하다"가 아니라 "L7에 넣으면 답이 latent에 덜 의존한다"로 씁니다.
- **의존도가 높다고 정확도가 높지는 않습니다.** latent에 많이 기대는 CODI와 L13→L0도 latent 없이 학습한 모델(52.16)과 정확도가 같습니다.
- latent를 비운 모델이 풀이를 글로 쓰는 것은 [latent 없이 학습한 모델의 간격 0 현상](2026-11-09-mf-c-no-latent.html)과 같은 모습입니다. 교사 CE(①)로 풀이 글쓰기를 함께 배운 모델이, latent 자리가 평소와 다르면 글쓰기 방식으로 돌아가는 것으로 보입니다(해석).

## 한계

- GSM8K만 평가한 탐색적 분석이고 시드 하나입니다(CODI와 L13→L0은 네 벤치마크를 모두 평가했습니다).
- 0 벡터와 잡음은 학습 때 본 적 없는 입력이라, 하락폭에는 "낯선 입력" 효과도 섞여 있습니다.

## 일지에서의 이름

CODI `codi6_*`, L13→L0 `w14_*`, Middleflow `causal_*`와 `skip_with_gap`. 계산식 비율은 11-24 저장된 평가 기록을 다시 읽어 셈.
