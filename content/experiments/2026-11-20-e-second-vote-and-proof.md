**답을 하나 기각한 다음 멈춰도 되는지 판단하기 위해 두 가지 근거를 시험했습니다.** 서로 다른 자연 풀이의 중간 증거를 합쳐야만 최적값을 증명할 수 있었던 경우는 24쌍 중 0개였습니다. 또 다른 두 모델에서는 남은 답을 지지하는 풀이가 두 개 생길 때까지 기다려 봤습니다. 원래 생성 순서에서는 두 모델 모두 추가로 고친 문항이 없었고, 전체 토큰을 10% 줄인다는 기준에도 미달했습니다. [선행 실험에서 올바른 반박 뒤 남은 오답을 고른 사례](2026-11-20-c-automatic-witness.html)

## 두 풀이의 근거를 합쳐야만 증명이 되는가

예를 들어 최솟값이 216임을 증명하려면 가능한 값이 항상 216 이상임을 보이고, 실제 조건을 만족하면서 216을 달성하는 예를 제시할 수 있습니다. 한 풀이에는 하한만 있고 다른 풀이에는 실현값만 있다면 두 근거를 결합할 이유가 있습니다.

기존 자연 생성 중 네 문항에서 LIMO A2와 저자 QFFT의 답변을 각각 6개씩 읽었습니다. 모델과 문제를 같게 두고 미리 정한 세 쌍씩, 총 24쌍을 만들었습니다. 양쪽이 모두 생성 중인 89개 시점에서 실제 생성 토큰을 같은 길이로 잘라 평가했습니다. 비교 단위는 4문항이며, 여러 시점에서 같은 쌍을 반복 관찰했습니다. [원문 생성 조건과 결과](2026-11-20-d-symmetry-original.html)

| 판정 조건 | 해당 쌍 / 24쌍 |
|---|---:|
| 한쪽에 허용점, 다른 쪽에 하한 수식이 보임. 일반식에 이미 적은 값을 대입하는 경우 포함 | 3 |
| 다른 쪽이 해당 문제의 하한을 수식으로 끝까지 씀 | 2 |
| 각자 불완전하고, 서로 합쳐야만 정답이 증명됨 | 0 |

부피가 216인 직육면체에서 겉넓이를 최소화하는 문제가 이유를 보여 줍니다. 한 A2 풀이는 1,024토큰 시점까지 겉넓이 216이라는 하한과 등호 조건 xy=yz=zx를 썼습니다. 다른 풀이는 정육면체 한 변이 ∛216이라고 썼습니다. 언뜻 둘이 서로 빠진 근거를 제공한 듯 보입니다. 하지만 양의 변에서 xy=yz=zx이면 x=y=z이고, 첫 풀이만으로도 부피 조건 xyz=216에서 한 변 6을 얻습니다. 서로 다른 두 원문 이상, 각 모델에서 최소 한 문항이라는 기준을 충족하지 못해 이 방식의 GPU 확대를 보류했습니다.

허용점과 전역 경계를 합치는 방식은 LLM4MIP에서 이미 역할을 나눈 모델과 최적화 솔버로 연구됐습니다. 이번에 시험한 범위는 역할 지시 없이 자연히 생성된 두 풀이가 수학적으로 서로를 필요로 하는지입니다. 판독자는 한 명이었고, 일반식을 대입한 경우를 인정하는지에 따라 표 첫 두 줄의 수가 달라집니다. [LLM4MIP 연구진의 방법과 비교 실험](https://llm4mip.github.io/skill/)

## 남은 값이 두 번 실제로 나왔을 때 멈추면 어떨까

다음 조사에서는 연구팀이 복원한 S1.1-A2와 QFFT 논문 저자가 공개한 QFFT-S1-7B의 저장된 출력을 비교했습니다. 두 모델에 같은 프롬프트로 생성한 34문항 × 16개 답변이 있었습니다. 기존 다섯 최적화 문항에서만 풀이 중간의 좌표를 검산하고, 나머지 29문항에서는 답 합의를 사용했습니다. 원래 순서에서 2개, 4개, 6개까지만 읽으며 정답을 채점하기 전에 정책 결정을 저장했습니다.

| 원 순서의 종료 조건 | S1.1-A2 정답 / 평균 토큰 | 저자 QFFT-S1-7B 정답 / 평균 토큰 |
|---|---:|---:|
| 단순 합의 | 32/34 / 14,257 | 32/34 / 12,029 |
| 검산 후 한 종류의 값만 남으면 종료 | 32/34 / 13,697 | 32/34 / 11,228 |
| 남은 값을 두 개 이상의 풀이가 실제 제출해야 종료 | 32/34 / 13,948 | 32/34 / 12,029 |
| 검산 없이 단독 최다 득표 값이 두 표 이상이면 종료 | 32/34 / 13,186 | 32/34 / 11,942 |
| 6회 고정 투표 | 32/34 / 21,898 | 32/34 / 18,499 |

단순 합의 대비 두 표 방식의 토큰 절감은 S1.1-A2 2.17%, 저자 QFFT-S1-7B 0%였습니다. 두 모델 모두 처음 두 풀이에서 한 표만 살아남은 경우는 원 순서에서 163번 하나였고, 그 한 표가 이미 정답 −35/9였습니다. 다음 두 번을 읽는 데 각각 8,531토큰, 9,090토큰이 더 들었습니다. 실제로 검산한 다섯 문항에서 세 가지 합의 규칙의 정답 수는 S1.1-A2 4/5, 저자 모델 5/5로 같았습니다.

**일부 순서에서는 두 번째 표를 기다리는 것이 도움이 됐습니다.** 16곳에서 시작해 정방향·역방향으로 읽는 32가지 순서에서 저자 QFFT-S1-7B는 기존 한 표 종료와 비교해 8개 문항·순서 조합을 더 맞혔습니다. 43번에서 3개, 163번에서 5개였고 다른 문항에서 새로 틀린 조합은 없었습니다.

- 43번의 한 순서에서는 두 답을 읽고 90만 남았습니다. 다음 두 답을 읽으면 그 시점 투표가 참값 70√2로 바뀌었습니다. 입력과 출력 비용은 20,772토큰에서 43,479토큰으로 늘었습니다.
- 163번의 다른 순서에서는 4개를 읽었을 때 21만 남았습니다. 마지막 두 개를 더 읽자 참값 −35/9를 선택했습니다. 비용은 11,079토큰에서 29,400토큰으로 늘었습니다.

32순서 전체에서 S1.1-A2는 한 표와 두 표 방식이 모두 997/1,088이었습니다. 저자 모델은 1,027/1,088에서 1,035/1,088로 올랐습니다. 1,088은 **같은 34문항을 32가지 순서로 재생한 수**입니다. 두 표 방식의 단순 합의 대비 토큰 절감은 각각 2.53%, 1.90%였습니다. 비용은 프롬프트와 저장된 출력을 두 모델의 토크나이저로 다시 센 값입니다.

합의의 강도로 표본 수를 정하는 방법에는 Adaptive-Consistency와 Certified Self-Consistency라는 선행이 있습니다. 이번 질문은 수학적 반박 뒤 한 표만 살아남은 시점에서 추가 두 번의 생성 비용을 지불할 가치가 생기는지였습니다. 원 순서에서는 회복한 문항이 없고 순서를 바꿔 생긴 이득도 두 문항에 집중됐으므로, 이 두 표 규칙의 확대 실험은 보류했습니다.
