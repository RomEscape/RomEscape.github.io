## 한 줄 요약

이 프로젝트의 품질 점수는 대부분 **LLM 자동 평가**(대형 언어 모델이 기준표로 채점)입니다. 숫자만 받으면 믿을 수 없어서, **항목마다 근거를 먼저 쓰고 그 인용이 실제 답에 있는지 검사한 뒤** 0~1 종합값을 내는 루브릭 채점 도구를 만들었습니다. 기존 Neeko 방식 채점에 쓰던 gpt-3.5-turbo가 서비스를 끝내서, 결과를 보기 전에 정한 기준으로 **gpt-6-luna + 인물 프로필 전체**를 새 평가 모델로 골랐습니다. 이 과정에서 **같은 답의 평균이 평가 모델에 따라 6.64점에서 5.21점까지** 바뀌었고, **평가에 넘기는 프로필에 따라 5.14점에서 3.74점까지** 바뀌었습니다. 평가 조건이 다른 점수끼리는 비교하지 않습니다. 따로 잰 사람다움(AI 티) 점수는 실제 사람 인터뷰 5.67점, 모델 답 2.11~2.90점이었습니다.

## 왜 필요했나

- 사람 평가는 비싸고 느려서 공인 시험(T-002)에만 씁니다. 에폭 고르기, 자료 개선 효과 확인 같은 일상 판단은 LLM 자동 평가로 합니다.
- 그런데 LLM 평가는 점수만 던지면 왜 그 점수인지 확인할 수 없고, 같은 답도 평가 모델을 바꾸면 점수가 달라집니다.
- 그래서 "숫자만 내는 평가는 무효"라는 원칙을 정했습니다. 항목별 점수와 근거를 먼저 내고, 그다음에 0~1 사이 종합값을 내야 합니다.

## 용어 풀이

| 용어 | 뜻 | 이 글에서의 실제 값 |
|---|---|---|
| LLM 자동 평가 | 대형 언어 모델이 정해진 기준표로 답을 채점하는 것. 사람 점수가 아님 | 이 글의 모든 점수 |
| 루브릭 | 항목, 점수마다의 기준 문장, 허용하는 흠의 수를 미리 적은 채점 기준표 | 한 턴 5항목, 대화 8항목 등 |
| Neeko 방식 평가 | 인물 대화 모델 연구(Character-LLM, Neeko)에서 쓰는 1~7점 채점. 행동, 말투, 관련성, 안정성, 환각, 실제 지식, 가상 지식의 7개 영역 | 멀티턴은 역할 유지(transfer)를 더해 8개 영역 |
| 대조 답 | 일부러 틀리게 만든 답. 평가 모델이 이것을 낮게 주는지로 구별력을 잼 | 다른 질문의 답, 다른 인물의 답 |
| AUC | 진짜 답과 대조 답을 점수로 얼마나 잘 가르는지 나타내는 값. 1이면 완벽, 0.5면 우연 | 기준 0.90 이상 |
| 통제 문항 | 정답(높게 줘야 할지 낮게 줘야 할지)을 미리 아는 문항. 평가 모델을 검증할 때 씀 | 132개(변환기 81, 안전 51) |
| 부트스트랩 95% 구간 | 문항을 다시 뽑아 계산을 여러 번 되풀이해 얻은 값의 범위 | 두 모델 차이의 구간이 0을 품으면 차이로 보지 않음 |
| 평가 모델 간 일치도 | 여러 평가 모델(또는 같은 모델의 반복)이 얼마나 같은 점수를 주는지 | κ 같은 일치 계수 |
| 사람다움(AI 티) | 답이 실제 사람의 말처럼 들리는지를 1~7점으로 매긴 자체 지표 | 실제 사람 인터뷰 5.67점 |
| 캡슐 프로필, 프로필 v2 | 평가할 때 평가 모델에 넘기는 인물 설명 글. 캡슐 프로필은 서비스 패키지에 든 판(7.7KB), 프로필 v2는 사료로 새로 쓴 긴 판(41.9KB) | 같은 답이 5.14점, 3.74점 |

## 무엇을 했나

1. **루브릭 채점 도구를 만들었습니다(10-28).** 평가 모델은 항목마다 근거 문장을 먼저 쓰고, 근거가 답의 어느 문장인지 위치를 붙입니다. 도구는 다음을 검사하고 하나라도 어긋나면 그 판정을 무효로 돌립니다.
   - 인용한 글이 실제 답에 있는지, 사용자 말이나 다른 글을 답처럼 인용하지 않았는지
   - 점수마다 허용하는 흠의 개수(예: 치명 흠 0, 중대 흠 0)와 매긴 점수가 맞는지
   - 판단할 수 없을 때 "판단 불가"를 쓰고 점수를 지어내지 않았는지
   - 안전 관문: 치명적인 흠이 있으면 다른 항목이 좋아도 종합값을 0.25 이하로 묶음
2. **보고 방식도 정했습니다.** 문항 단위 부트스트랩 95% 구간, 같은 문항끼리 짝지은 비교, 이보다 작으면 차이로 보지 않는 최소 검출 차이, 평가 모델 간 일치도를 함께 냅니다. 계산할 수 없으면 "보고 불가"로 적습니다.
3. **평가 모델을 검증했습니다.** 정답을 아는 통제 문항 132개로 평가 모델이 맞는 쪽으로 점수를 주는지 확인합니다.
4. **판정 규칙은 결과를 보기 전에 일지에 적었습니다.** 결과를 본 뒤에 규칙을 바꾸지 않습니다. 바꿔야 하면 그 사실을 그대로 적습니다.
5. **Neeko 평가 모델 교체(11-02).** gpt-3.5-turbo가 2026-10-23에 서비스를 끝냈습니다. 원 논문 코드는 인물 프로필의 첫 문단만 평가 모델에 넘깁니다(조수미 프로필 25,151자 가운데 645자). 후보 평가 모델과 프로필 범위(첫 문단, 전체)를 바꿔 가며 같은 답을 다시 채점했습니다.
   - 재료: 공식 모델 세 인물의 한 턴 답(인물당 10문항)과 대조 답(다른 질문의 답으로 관련성, 가상 지식을 보고, 다른 인물의 답으로 행동, 말투를 봄)
   - 미리 정한 기준: 유효 점수 98% 이상, 대조 답 평균이 진짜 답보다 2점 이상 낮음, AUC 0.90 이상
6. **평가에 넘기는 프로필 효과를 쟀습니다.** 같은 답을 캡슐 프로필과 프로필 v2로 각각 채점했습니다.
7. **사람다움(AI 티)을 따로 쟀습니다.** 실제 사람 인터뷰, 일부러 AI 비서 말투로 고쳐 쓴 글, 모델 답을 같은 기준으로 채점했습니다. 이어 자료를 고쳐 쓰면 사람다움이 오르는지 시범했습니다.

## 실제 예시

한 판정이 무효가 되는 경우를 순서대로 보겠습니다(설명용 예시).

1. 평가 모델이 "말투 6점, 근거: 답 2번 문장 '…하였소'"라고 씁니다.
2. 도구가 답 2번 문장에 실제로 그 글이 있는지 찾습니다. 없으면 인용 실재 검사 실패로 이 판정은 무효입니다.
3. 근거에는 "치명 흠 1개"라고 써 놓고 6점을 줬다면, 6점이 허용하는 흠 띠(치명 0)와 맞지 않아 무효입니다.
4. 모든 검사를 통과한 판정만 항목 점수를 0~1로 바꿔 평균하고, 안전 관문에 걸리면 0.25 이하로 묶어 종합값을 냅니다.

평가 모델 교체에서는 같은 답 묶음의 평균이 아래처럼 바뀌었습니다(다음 절 표).

## 결과

표 읽는 법: 같은 답 묶음을 평가 모델과 프로필 범위만 바꿔 다시 채점한 결과입니다. "같은 답 평균"이 다르면 같은 모델이라도 점수가 다르게 나온다는 뜻입니다. "대조 최소 차이"와 "AUC"가 클수록 틀린 답을 잘 가려냅니다. 모두 LLM 자동 평가입니다.

| 평가 모델, 프로필 범위 | 같은 답 평균(7점) | 대조 답과의 최소 차이 | AUC 최소, 평균 |
|---|---|---|---|
| gpt-3.5-turbo, 첫 문단(종료된 옛 방식) | 6.64 | 없음 | 없음 |
| gpt-4.1-mini, 첫 문단 | 6.51 | 2.63 | 0.867, 0.921 |
| gpt-4.1-mini, 전체 | 6.75 | 3.00 | 0.906, 0.970 |
| gpt-5.6-terra, 첫 문단 | 5.39 | 2.00 | 0.851, 0.930 |
| gpt-5.6-terra, 전체 | 5.33 | 2.07 | 0.848, 0.952 |
| gpt-6-luna, 첫 문단 | 5.33 | 2.33 | 0.866, 0.944 |
| **gpt-6-luna, 전체(고름)** | **5.21** | **2.27** | **0.911, 0.973** |

- 미리 정한 기준을 대조 종류마다 각각 적용하면 gpt-6-luna 전체와 gpt-4.1-mini 전체가 통과했습니다.
- gpt-4.1-mini 전체는 210개 점수 가운데 172개가 7점이었습니다(gpt-6-luna 전체는 34개). 점수가 꼭대기에 몰리면 좋은 모델끼리 구별이 어려워 gpt-6-luna를 골랐습니다.
- 옛 방식은 점수 210개 가운데 205개가 6~7점이었고, 같은 답에 대한 옛 점수와 새 방식 점수의 상관은 0.03이었습니다. 옛 방식은 답 사이의 차이를 거의 가르지 못했다는 뜻입니다.
- 옛 방식(6.64)과 새 방식(5.21)의 차이는 모델이 나빠진 것이 아니라 평가 조건이 바뀐 것입니다. 그래서 4~5월에 옛 방식으로 매긴 6점대 후반 점수와 지금 점수는 비교하지 않습니다.

표 읽는 법: 같은 답을 평가 모델(gpt-6-luna)은 그대로 두고, 평가에 넘기는 인물 프로필만 바꿔 채점한 값입니다.

| 모델 답 | 캡슐 프로필(7.7KB) | 프로필 v2(41.9KB) |
|---|---|---|
| 김홍도 7.8B, 한 턴 | 5.14 | 3.74 |
| 김홍도 7.8B, 멀티턴 | 4.15 | 2.71 |
| 정선 7.8B, 한 턴 | 5.38 | 4.21 |
| 정선 7.8B, 멀티턴 | 4.37 | 3.33 |

- 프로필이 자세할수록 평가 모델이 사실 어긋남을 더 많이 찾아내 점수가 낮아졌습니다. 대표 점수는 gpt-6-luna + 캡슐 프로필로 정했습니다.
- 엄격한 자동 평가는 사람보다 낮게 줍니다. 사람 평가 6.04점을 받은 조수미 모델이 블라인드 LLM 자동 평가의 T-002 8항목으로는 4.80점, gpt-6-luna 멀티턴으로는 4.79점이었습니다. 약 1.2점 차이입니다.

표 읽는 법: 사람다움(AI 티) 1~7점입니다. 실제 사람 인터뷰와 일부러 AI 비서 말투로 바꾼 글이 양 끝의 눈금입니다. 이 도구는 사람 평가와 맞춰 본 적이 없는 자체 지표입니다.

| 대상 | 사람다움 |
|---|---|
| 실제 사람 인터뷰(42개, 5점 이상 88%) | 5.67 |
| AI 비서 말투로 고쳐 쓴 대조 글(30개) | 1.83 |
| 공식 모델 한 턴 답: 조수미, 김홍도, 정선 | 2.90, 2.11, 2.26 |
| 공식 모델 멀티턴 답: 조수미, 김홍도, 정선 | 1.68, 1.58, 1.68 |

자료를 고쳐 쓰면 사람다움이 오르는지도 시범했습니다.

- 대화를 통째로 고쳐 쓴 자료는 사람다움이 0~+0.6점 올랐습니다. 사람과의 차이(3~4.5점)에 비하면 작아서 "자료를 고친 뒤 재학습"이라는 처음 권장을 보류했습니다.
- 고친 자료 1,000행으로 짧게 학습한 어댑터를 붙여 비교하니 멀티턴 Neeko 점수는 김홍도 +0.53, 정선 +0.66, 조수미 +0.20 올랐지만, 사람다움은 +0.18~+0.36에 그쳤습니다. 미리 정한 기준(사람다움 +0.3 이상)에 못 미쳐 기존 자료로 재학습하기로 했습니다.

## 그래서 무슨 뜻인가

- **LLM 자동 평가의 점수는 평가 조건의 값입니다.** 평가 모델과 넘기는 프로필이 바뀌면 같은 답도 1점 넘게 달라집니다. 점수를 비교할 때는 늘 같은 조건으로 다시 매긴 값만 씁니다.
- **근거를 먼저 쓰게 하면 무효 판정을 걸러낼 수 있습니다.** 인용이 실제로 있는지, 점수와 흠의 개수가 맞는지 기계로 검사할 수 있기 때문입니다.
- **사람다움은 말투 다듬기로 풀리지 않습니다.** 모델 답은 실제 사람보다 AI 비서 말투에 훨씬 가깝고, 자료의 말결을 고쳐도 크게 오르지 않았습니다.

## 한계와 남은 일

- 평가 모델 고르기 기준을 "대조 종류마다 각각" 적용한다는 점은 미리 적지 않았습니다. 평균으로 읽으면 다른 후보가 뽑혔을 수 있습니다.
- 사람다움 지표는 사람 평가와 맞춰 본 적이 없습니다. 사람 평가와의 대조가 필요합니다.
- 통제 문항 132개는 변환기(81개)와 안전(51개)용이고, 일반 대화 품질용 통제 문항은 이 안에 없습니다.
- 사람 평가(T-002)와 LLM 자동 평가의 차이(약 1.2점)는 몇 개 판으로만 확인했습니다.
