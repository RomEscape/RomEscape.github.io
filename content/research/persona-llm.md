## 한 줄 요약

실존 예술가 세 사람처럼 말하는 한국어 대화 모델을 만듭니다. 인물 프로필에서 학습 대화를 자동으로 만들고, 7.8B(78억 개 매개변수) 모델을 학습해 서비스용으로, 2.4B 모델을 시험용으로 씁니다. 자체 측정에서 **응답시간 평균 0.492초(기준 0.5초 이내), 사람 평가 6.10점(기준 5.2점 이상, 7점 만점)**으로 두 목표를 맞췄습니다. 11월에는 화가 모델이 자기를 3인칭으로 부르는 비율을 김홍도 25.2%에서 3.1%로, 정선 37.8%에서 7.8%로 줄인 새 판을 전달했고, 지금은 사용자에 대한 기억을 묻는 대화 자료를 보강하는 중입니다.

## 무엇을 만드나

| 인물 | 누구 | 말투 | 대화 말고 맡는 기능 |
|---|---|---|---|
| 조수미 | 소프라노 | 존댓말 | 화법 변환기 두 가지: 음악 작품 해설을 조수미 말투로(작품토론), 노래 평가 글을 조수미 말투로(가창지도) |
| 김홍도 | 조선 후기 화가(단원) | 하오체, 상대를 '그대' | 프롬프트 생성기(대화로 그림 요청을 모아 그림 생성 모델에 넘길 태그를 만듦), 미술 평가 글을 화가 말투로 바꾸는 화법 변환기 |
| 정선 | 조선 후기 화가(겸재) | 하게체, 상대를 '자네' | 김홍도와 같음 |

서비스는 한 인물마다 **납품 패키지(캡슐)** 하나로 나갑니다. 캡슐 안에는 대화 모델 하나와 기능별 작은 추가 학습 부분(어댑터), 규칙 코드가 들어 있습니다. 들어온 입력의 모양(평범한 문장인지, 다른 시스템의 답인지, 그림 요청인지)을 보고 어느 기능으로 보낼지 정하며, 기능을 바꿀 때 모델을 다시 띄우지 않습니다.

## 용어 풀이

표의 왼쪽은 용어, 가운데는 쉬운 뜻, 오른쪽은 이 연구에서의 실제 값입니다.

| 용어 | 뜻 | 이 연구에서의 예 |
|---|---|---|
| 페르소나 LLM | 특정 인물처럼 말하도록 학습한 언어 모델 | 조수미, 김홍도, 정선 모델 |
| 프로필 | 인물에 관한 사실과 말버릇을 정리한 글. 학습 자료를 만드는 재료이자, 대화 때 근거로 찾아 붙이는 글 | 조수미 77문단. 김홍도는 11월에 사료로 다시 써서 17,974자 |
| 7.8B, 2.4B | 모델의 크기(매개변수 수). B는 10억 | EXAONE 3.5 7.8B는 서비스용, 2.4B는 응답시간 시험용 |
| 에폭 | 학습 자료 전체를 한 바퀴 다 보는 단위 | 10에폭 학습 뒤 에폭마다 평가해 하나를 고름 |
| INT4, 양자화 | 모델의 숫자를 4비트 정수로 줄여 메모리와 속도를 아끼는 것 | 7.8B 모델 15.64GB → 5.39GB |
| QAT(학습 중 양자화) | 학습하는 동안 4비트 오차를 미리 겪게 해 줄인 뒤에도 성능이 덜 떨어지게 하는 방법 | 모든 대화 모델 학습에 씀 |
| LoRA, 어댑터 | 본 모델은 고정하고 작은 추가 부분만 학습하는 방법. 그 추가 부분이 어댑터 | 화법 변환, 프롬프트 생성 어댑터 |
| RAG(문서 검색 증강) | 질문과 관련된 문단을 찾아 모델 입력에 붙여 주는 방법 | 프로필에서 관련 문단 5개를 찾아 붙임 |
| DPO | 좋은 답과 나쁜 답을 짝지어 좋은 쪽을 고르도록 가르치는 학습 | 3인칭 버릇에는 효과가 없었음 |
| GRPO | 같은 질문에 답을 여러 개 뽑아 규칙 점수가 높은 쪽으로 고치는 강화학습 | 김홍도 3인칭 버릇 25.2% → 3.1% |
| greedy 디코딩 | 매번 가장 확률이 높은 낱말만 고르는 생성 방식. 같은 질문에 늘 같은 답이 나옴 | 응답시간 시험 설정 |
| LLM 자동 평가 | 다른 큰 언어 모델이 기준표에 따라 답을 채점하는 것. 사람 점수가 아님 | 대화 품질, 안전성, 기능 평가 |
| 캡슐 | 모델과 실행 코드를 묶은 납품 패키지 | 인물마다 하나 |

## 점수를 읽을 때 주의할 점

이 연구에는 성격이 다른 점수 세 가지가 나옵니다. 서로 바로 비교하면 안 됩니다.

| 점수 | 누가 매기나 | 어디에 씀 |
|---|---|---|
| 사람 평가(1~7점) | 평가자 3명이 서로 보지 않고 매김 | 대화 품질 시험(T-002)에만 씀 |
| LLM 자동 평가 | 다른 언어 모델이 기준표로 채점 | 에폭 고르기, 안전성, 기능 비교. **평가 모델을 바꾸면 같은 답도 6.64점에서 5.21점이 됩니다**([평가 모델 교체 기록](../experiments/2026-11-02-persona-judge-reliability.html)) |
| 규칙 측정 | 코드가 셈 | 응답시간, 영어가 남은 칸 수, 3인칭 비율 같은 것 |

4월 이전의 6점대 후반 점수는 지금은 서비스가 끝난 옛 평가 모델로 매긴 값이라 11월의 5점대 점수와 비교할 수 없습니다.

## 주요 결과

- **두 시험 목표를 자체 측정으로 맞췄습니다.** 응답시간 평균 0.492초(조수미 0.495, 김홍도 0.496, 정선 0.486초, 기준 0.5초 이내), 사람 평가 6.10점(기준 5.2점 이상). 공인 평가 전 값입니다. 여유가 1% 남짓이라, 11월 6일에 2.4B 모델과 greedy 디코딩을 시험 설정으로 정했습니다(0.261초).
- **모델 크기는 속도와 품질을 맞바꿉니다.** 2.4B는 7.8B보다 빠르지만 같은 대화 안에서 앞 답의 8자 조각을 17.14% 다시 씁니다(7.8B 3.60%, 학습 자료 3.77%). 그래서 서비스는 7.8B, 시험은 2.4B로 나눴습니다.
- **평가 모델이 바뀌면 점수가 바뀝니다.** 같은 답이 평가 모델에 따라 6.64점(gpt-3.5-turbo)에서 5.21점(gpt-6-luna)이 되고, 평가 모델에게 넘기는 프로필이 달라도 5.14점과 3.74점으로 갈립니다. 그래서 점수를 비교할 땐 평가 모델과 프로필을 같게 맞춥니다.
- **화가가 자기를 3인칭으로 부르는 버릇은 DPO로는 고쳐지지 않았고 GRPO로 고쳐졌습니다.** 김홍도 25.2% → 3.1%, 정선 37.8% → 7.8%(규칙 측정, 강화학습 전 바탕 모델 대비). DPO는 세 에폭 모두 바탕과 차이가 없었습니다.
- **안전성은 기반 모델보다 낫지만 목표에는 아직 못 미칩니다.** 위반 응답률 김홍도 9.0%, 정선 21.4%(두 화가는 11월 새 2.4B 학습판), 조수미 모델 20.6%(LLM 자동 평가). 11월 5일 새 7.8B 판에서는 김홍도가 21.5%로, 같은 시험에서 2.4B 학습판(10.2%)의 두 배라 원인을 찾아야 합니다.
- **기능별 어댑터가 효과가 있었습니다.** 노래 평가 글을 조수미 말투로 바꿀 때 지적 내용 보존이 79.8%에서 99.3%로 올랐습니다(LLM 자동 평가). 프롬프트 생성기는 규칙 기반 가상 사용자와의 대화에서 목표 그림 태그를 90.0~100% 맞췄습니다.

## 아직 모르는 것

- 사람 평가는 대화 품질 시험(T-002)에만 있습니다. 나머지는 LLM 자동 평가와 규칙 측정이라, 사람이 느끼는 품질과 얼마나 맞는지 모릅니다.
